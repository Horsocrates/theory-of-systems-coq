### Математика/index — новая секция «Бесконечность и цена аксиом»
Встала между «Математика процессов» и «Граница финитизации». Основание — исследование двумя Explore-проходами: Coq-инвентарь (`src/settheory/` + кластер `P4_Eliminates_*`/`P4Prohibits*` + `ZFCAxiomLedger.v`) и проза Части X «Теория множеств без аксиомы выбора» (6 глав, уже на сайте).

- **Такты:** текущее положение (актуальная бесконечность Кантора → Рассел → кризис оснований → **ZFC как ограда**; невысказанная цена: Витали, Банах–Тарски, вполне-упорядочение ℝ; независимость CH/AC по Гёделю–Коэну) → **смена категории** (множество = Система, ∈ = роль, ∞ = процесс P4, выбор = правило L5; сильная аксиома = склейка законного правила и незаконного завершённого объекта) → **таблица по 9 аксиомам ZFC** → расплата (одна цена — завершённый Powerset/`P(ℕ)`).
- **Честные калибровки (решения сессии):**
  - «без аксиом» → точно: «без **теоретико-множественных** аксиом ZFC при двух логических законах **L3 + L4**»; L4 формально = слабый выбор (`constructive_indefinite_description`), но по **одному ∃**, не по семейству → «без выбора над семействами».
  - CH/форсинг — факты **о самой ZFC**, не поданы как решённое у нас.
  - Реестры (`ZFCAxiomLedger` и т. п.) — **классификация**, не теоремы; клетки таблицы обоснованы backing-файлами.
  - Scope-честность: конечная детерминированность (не борелевская), Крускал — для конкретных семейств.

### Математика/index — «Избранные результаты» на генерации
- Переведены с 5 ручных буллетов на **генерацию из реестра HIGHLIGHTS**.
- **Пайплайн:** источник-витрины (пока сайдкар `quartz/tools/highlights-vitrina.md`, 9 матзаписей) → `quartz/tools/highlights2md.ps1` (чистый ASCII, без BOM) → блок между маркерами `<!-- HL:BEGIN/END -->` (инъекция, как `catalog2md`). Формат витрины: `<!-- ВИТРИНА theme=… level=… part=… cost=… show=… -->` + одна фраза.
- **Честность едет из источника:** H73 несёт `classic (L3); RH — exploratory`, 0-аксиомные — `0 акс` — сайт не переобещает.
- Итог: **9 результатов в 5 темах**; все 5 прежних флагманов сохранены (несчётность, выбор без AC, одна диагональ, Галуа, замыкание ℚ) + 4 новых (P4+L5 без ZFC, граница вычислима над ℚ, дзета как процесс, нестандартный анализ/Беркли, Каталан тремя путями).
