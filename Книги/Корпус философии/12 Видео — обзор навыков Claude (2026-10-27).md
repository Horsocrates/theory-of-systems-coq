## What the repo is
`zhuyansen/awesome-claude-video-skills` is a curated **awesome-list**, not a skill pack. It holds no SKILL.md of its own: just a README in English and Chinese, a machine-readable `data/skills.json` (generated 2026-10-26) and preview images.

- **Size:** 353 GitHub repos in 10 categories. The GitHub "About" text says 180, which is out of date.
- **Licence:** CC0 1.0 for the list itself; every listed project keeps its own licence.
- **Activity:** 1.1k stars, 107 forks, 42 commits. A github-actions bot commits a "Daily update" each day; the last was 2026-10-26, and the history I could see starts 2026-09-27.
- **Source:** the list is mirrored from agentskillshub.top, which refreshes every 8 hours.
- **How entries get in:** a "decision model" reads each README, not a person.
- **"Security" grades:** 344 SAFE, 9 CAUTION. Per the hub's own page, this is a 42-rule automated scan of the README and install steps, a first-layer check and "not a manual audit".
- **Their test (2026-10-11):** 16 skills each rendered the same 15-second promo on a machine with no video, image or voice API keys. All 16 passed four basic checks, taking 2.0–23.5 minutes. Claude Code with no skill also passed, in 4.4 minutes.
- **Their picks:** explainroo, onetake, and remotion-dev/skills.
- **Other sections:** "Made with Claude Opus 5.5" (4 projects) and two related lists.

**How I read it.** I took the list from `skills.json` and the README. For all 353 repos I read, read-only, the GitHub file listing and the raw README, SKILL.md, package.json and requirements files. I did this with curl/Node GET requests streamed into my own parser, because the gh CLI isn't installed. Nothing was cloned, installed or run. I then read about 25 relevant repos closely by hand.

## Table (all 353 entries; each name is a repo at github.com/<name>)
**How to read the columns**
- **SK**
  - **Y** – the repo contains a SKILL.md, which Claude Code can install. Some are written for Codex or Hermes but use the same format.
  - **Y+P** – it also ships a Claude Code plugin manifest.
  - **N** – no SKILL.md.
- **Engine "HTML→Chrome"** – an HTML/Canvas/SVG page is rendered frame by frame in headless Chrome (Playwright or Puppeteer) and encoded with FFmpeg.
- **Needs**
  - **local** – the README says it runs locally and/or needs no key.
  - **local\*** – I found no key or cost mentioned in the README or SKILL.md, so "local" is my inference.
  - **opt.** – optional.
- **Notes**
  - **ZH/PT/KO/FR/ES/TR/AR** – the docs are mainly in that language.
  - **Licence** – as GitHub detects it. NOASSERTION means GitHub didn't recognise the licence; "no LICENSE" means none was found.
  - **RU** – Russian or Cyrillic is noted only where a README states something. Everywhere else it is not stated.
- **Where values come from** – the engine and needs columns come from each repo's dependencies plus its README. Anything I inferred says so.
