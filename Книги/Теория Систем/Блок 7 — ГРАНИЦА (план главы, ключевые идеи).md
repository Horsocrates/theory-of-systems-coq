# Блок 7 — ГРАНИЦА: одна несущая стена (план главы, ключевые идеи)

## Роль и форма блока
- **Роль:** **кульминация** — топос-вопрос, мост к процессам, аудит стен, самоподобие.
- **Тезис:** у теории ровно ОДНА несущая граница — **H1/role-limit + L3 = P4** — и она ВНУТРИ собственного ядра.
- **E/R/R-линза:** обе ноты сходятся — позитивное самозаземление (старт, M1) и role-limit (предел) — **одна L4-асимметрия** (`positive→¬negative`), две её стороны.
- **Вход:** объект/время/целое/вертикаль построены. **Выход в Блок 8:** из границы ветвятся миры.

## Спина: 7.1 → 7.5

### 7.1 Топос-вопрос решён ХАРАКТЕРИЗАЦИЕЙ ✓
- Подобъект классифицируется Ω = SDisc ⟺ предикат **разрешим ∧ Roles-насыщен** (`char` строит классификатор; `char_classifies`, `char_unique` — 0-ax, **НЕ PI-стена**).
- **Две стены = характеризация:** классифицируем ⟹ разрешим (`classified_implies_decidable` = H1) ∧ Roles-насыщен (`classified_implies_saturated` = ярус Roles).
- ⚠ Вердикт: категория E/R/R — топос РОВНО на разрешимом Roles-насыщенном фрагменте; провал полноты = в точности H1 + ограничение Roles. **Не «ToS = топос».**
- ✓

### 7.2 Мост к процесс-онтологии ✓★
- **Статичный триад ↔ динамический P4-процесс — две грани ОДНОЙ субстанции** (`ERRProcessBridge`): динамика системы ЕСТЬ процесс; ℚ-траектория ЕСТЬ `RealProcess` (геом. ½-вещественное, произведённое категорной динамикой).
- **Терминирует (Element) / нет (role-limit) = категорный вырезать / слить = ОДНА граница H1.**
- Опоры: Гильберт = процесс {Q^N} (`ERRHilbertProcess`; завершённое пространство = ¬P4); Конституция = условие на процесс (`ERRProcessConstitution`; статичное R = role-limit); триада как gate→weight→status (`ERRProcess`, волна I).
- ✓★

### 7.3 Аудит стен — единственная несущая ✓
- **Три яруса стен:**
  - ярус I — **мнимые** (= черты: нет нулевого объекта, 2-клетки Prop-тонкие — не дефекты);
  - ярус II — **мягкие, РАСТВОРЕНЫ 5/5** (общий продукт `ERRProductGeneral`, разрешимый фактор `ERRFiniteQuotient`, под-система `ERRTierIIResidue`…);
  - ярус III — **несущая: H1/role-limit + L3 = P4**, нерастворима by design.
- ✓ (свод §12; H1-стратификация — `RoleLimitSpecies`)

### 7.4 Самоподобие ◇★ *(главный вывод арки)*
- ◇ **H1 раньше жил в приложениях — теперь установлен ВНУТРИ собственного ядра:** дуальность (ко)эквалайзеров (3.6), незавершимость башни (6.2), аттрактор = role-limit (4.5), топос-фрагмент (7.1).
- **Теория ДЕМОНСТРИРУЕТ ту самую границу, которую предсказывает повсюду** — самоподобна. Это и есть содержательный смысл «одной несущей стены».
- ◇★

### 7.5 Гранд-тур ✓ *(H1+P4 в миниатюре)*
- Одна дискретная 2-элементная система **SDisc** проведена через ВЕСЬ аппарат: объект / оператор / 2-клетка / эквалайзер ∥ коэквалайзер / образ / башня (`ERRGrandTour`).
- На одной системе видны обе ноты: позитивное начало и role-limit-граница — **H1+P4 в миниатюре**.
- ✓

→ *Теория замкнута на одной границе — Блок 8 показывает, как из неё ВЕТВЯТСЯ миры.*

## Честность (правила голоса)
- Топос — **характеризация**, не глухая стена и не «ToS = топос»: топос на разрешимом Roles-насыщенном фрагменте (⚠).
- Конструкции стандартны (теоркат); **новое = развитие изнутри + самоподобие H1** (HIGHLIGHTS H79) — не заявлять новую теорию категорий.
- Несущая граница (H1/role-limit + L3 = P4) **нерастворима by design** — это не недоработка, а суть.
- Обе ноты — одна L4-асимметрия: старт (позитив) и предел (role-limit).
