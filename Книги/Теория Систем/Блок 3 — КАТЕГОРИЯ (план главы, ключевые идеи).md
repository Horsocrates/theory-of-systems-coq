# Блок 3 — КАТЕГОРИЯ: системы складываются (план главы, ключевые идеи)

## Роль и форма блока
- **Роль:** замкнутая **Set-подобная категория** E/R/R-систем; композиция переехала с легаси-`System L` **на саму триаду**.
- **Тезис:** триада — полноценный категорный объект: **биполный, регулярный, 2-категорный, обогащённый над собой**.
- **E/R/R-линза:** **морфизм сохраняет Roles**; композиция возможна там, где **Rules гейтят** — продолжение ранговой асимметрии (2.4) на композицию.
- **Вход из Блока 2:** есть объект. **Выход в Блок 4:** статичный объект получает ВРЕМЯ.
- ⚠ **Кросс-реф, не дублировать:** Том II Часть XIV (общая ТК как ЯЗЫК математики, Setoid/Йонеда); здесь — категория ИМЕННО `FunctionalSystem`.

## Спина: 3.1 → 3.8

### 3.1 E/R/R-морфизм; Rules гейтят композицию ✓
- **`ERRMorphism`** = отображение носителей, **сохраняющее Roles** (Rules = рамка, не транспортируются); id, композиция; законы `err_id_left/right`, `err_comp_assoc` (reflexivity — композиция функций).
- **Rules гейтят составимость:** `product_closed` — equiv ДА, **connex НЕТ** ((T,F)/(F,T) несравнимы) ⇒ Rules — твёрдый ярус (продолжение 2.4).
- ✓

### 3.2 Произведение и копроизведение ✓
- **Настоящие универсальные** (медиатор единствен): `fs_product` (+ общее `ERRProductGeneral` для ЛЮБОЙ product-closed конституции); `sum_rel` — копроизведение (инъекции / копара / единственность).
- Проекции `fs_proj1/proj2` = fst/snd как морфизмы.
- ✓

### 3.3 Под-система / фактор ✓
- **Дуальная пара.** Под-система `fs_subsystem` (restriction-stable конституция ⇒ настоящая под-`FunctionalSystem`, `fs_incl`); **фактор** `fs_quot` коарсенит Roles до конгруэнции (эпиморфизм).
- ✓

### 3.4 Изоморфизм = mono+epi; первая теорема об изоморфизме ✓⚠
- `iso` = **mono + epi**; refl / sym / trans.
- **Первая теорема об изоморфизме — ЛОКАЛИЗОВАННАЯ:** `kernel f` конгруэнтно ⟺ `roles_collapsing f` (структурное препятствие); остаток = инъективность медиатора.
- ⚠ Честно: локализованная, не классическая полная (препятствие явно названо).
- ✓⚠

### 3.5 Терминал / инициал; нет нулевого объекта ✓
- Терминальный (unit) / инициальный (Empty_set) объекты + универсальность.
- **Нет нулевого объекта** — это **черта** set-подобия, не дефект.
- ✓

### 3.6 Конечная биполнота ✓◇
- **Все конечные (ко)пределы:** эквалайзеры + пулбэки (пределы), коэквалайзеры + пушауты (копределы).
- ◇ **Дуальная асимметрия (превью H1):** эквалайзер **ВЫРЕЗАЕТ** носитель (Element, конкретно) / коэквалайзер **СЛИВАЕТ** в Roles (полная единственность 0-ax, но carrier-merge = стена role-limit).
- ✓

### 3.7 Регулярность ✓
- **Всякий морфизм = (эпи на образ) ∘ (моно-вложение);** образ = под-система на достигнутых элементах.
- ✓

### 3.8 2-категория ✓⚠
- **Roles = 2-клетки** (категорный P3 «одинаково с точки зрения системы»); внутренний hom — категория **обогащена над собой**; композиция/единица как НАСТОЯЩИЕ морфизмы (self-enriched).
- ⚠ 2-клетки Prop-тонкие.
- ✓

### (доп.) Категория явно + автоморфизмы + биекции *(волна I)*
- **`ERRCategory`** ✓ — E/R/R **есть категория** в явных аксиомах (объекты = конечные role-метченные структуры; морфизмы сохраняют роли+правила; id / композиция / ассоциативность / единичные законы). Конкретная опора под 3.1.
- **`ERRAutomorphism`** ✓⚠ — автоморфизмы = обратимые ограниченные морфизмы; **дискретная симметрия S_N выведена**; ⚠ непрерывная **SU(N) постулируется** (нужна топология, нет в различении); N²−1 = размерность алгебры Ли. **Forward-ref Блок 8** (группы автоморфизмов → калибровка/СМ).
- **`ERRBijections`** ✓ — четыре биекции: **одна структура отвечает на четыре вопроса** (Процесс↔ERRSystem, Сжатие↔Физика, Декогеренция↔Затухание, Наблюдатель↔Компрессор).

→ *Статичный объект разобран как категория — Блок 4 даёт ему ВРЕМЯ (динамика, две стрелы).*

## Честность (правила голоса)
- Первая теорема об изоморфизме — **локализованная** (препятствие названо), не классическая.
- 2-клетки **Prop-тонкие** (⚠).
- ⚠ **SU(N)** в автоморфизмах **постулируется**, не выводится.
- ⚠ НЕ дублировать общую ТК Тома II ч. XIV — здесь категория именно `FunctionalSystem`.
- Дуальная асимметрия (ко)эквалайзеров — ◇ **наблюдение** (превью H1), не отдельная теорема.

## Аппендикс A — формальные якоря Блока 3 *(в конец тома; все 0 ax сверх `classic`=L3)*
- `ERRComposition` — `ERRMorphism`, `err_id_left/right`, `err_comp_assoc`, `product_closed` (`equiv_product_closed` / `connex_not_product_closed`), `fs_proj1/proj2`.
- `ERRProductUniversal` / `ERRProductGeneral` — `fs_pair`, `product_proj1/proj2`, `product_mediator_unique`; общий продукт.
- `ERRCoproduct` (+ `ERRCoproductEmergence`) — `sum_rel`, инъекции, медиатор.
- `ERRQuotient` — `fs_quot`; `ERRTierIIResidue` — `fs_subsystem` / `fs_incl`.
- `ERRIso` — `iso` = mono+epi, refl/sym/trans; `ERRFirstIso` — `kernel`, `roles_collapsing`, локализованная теорема.
- `ERRTerminalInitial` — терминал/инициал, нет нулевого; `ERRFiniteQuotient` — растворение препятствий на разрешимых носителях (`mediator_inj_iff_f_inj`).
- `ERREqualizer` / `ERRCoequalizer` — конечная биполнота; `ERRImageFactorization` — регулярность.
- `ERR2Category` / `ERR2CategoryHom` / `ERREnrichedComposition` — 2-клетки, внутренний hom, self-enriched.
- *(волна I)* `ERRCategory` (`err_category_synthesis`), `ERRAutomorphism` (`err_automorphism_synthesis`, ⚠ SU(N) постулируется), `ERRBijections` (`four_bijections`).
