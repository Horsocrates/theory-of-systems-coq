# Блок 1 — ВХОД: от A=∃ к E/R/R (план главы, ключевые идеи)

## Роль и форма блока
- **Роль:** фундамент. Деривационная цепь `A=∃ → различение → L1–L5 → P1–P4 → E/R/R`.
- **Тезис блока:** E/R/R — не постулат, а **конец дедуктивной цепи**.
- **E/R/R-линза блока** (книга и есть E/R/R-разбор ToS): разбираемая система = сам **АКТ РАЗЛИЧЕНИЯ** (минимальная система); Rules = L1–L5, Roles = разделение A / ¬A, Elements = A.
- **Самодостаточность:** формальная цепь + forward-ref на Том I «Метафизика» («почему различение» / Логика / ЗДО — **вперёд**, не назад). Метафизику здесь не переоткрываем.
- **Обе ноты звучат сразу:** единица (M1, точно в 1.2) и граница (P4, в 1.4).

## Спина: 1.1 → 1.5

### 1.1 Первичный факт `A=∃` ◇
- Существование — **первичный факт, не аксиома**. Самосвидетельствует: отрицание требует существующего отрицающего (**¬∃ → ∃**).
- **Позитивный старт:** начинаем с НАЛИЧИЯ, не с пустоты (нота M1).
- Статус записи `A=∃`: символическая, не формула CIC; **граница формализации** — формализм начинается со СЛЕДСТВИЯ (с акта различения), а не с самого факта.
- Forward-ref: «почему есть нечто, а не ничто» / Логика / ЗДО → Том I.
- ◇ *(не теорема; примат единицы-как-ЧИСЛА — в 1.2)*

### 1.2 Акт различения = рождение ПЕРВОЙ ЕДИНИЦЫ ✓ *(точный якорь M1)*
- **Один акт различения ЕСТЬ единица.** ✓ `one_distinction_exists` (distinction_count = 1, свидетель `[distinction_of True]`).
- **Ноль = пустой список различений = ОТСУТСТВИЕ.** ✓ `zero_distinctions` (distinction_count = 0, свидетель `[]`); счёт = добавление различения (`distinction_count_succ`).
- ЗДЕСЬ точная опора M1 «начинаем с 1»: единица первична, ноль производен (отсутствие различений). Следствие — **ℕ от 1**.
- Запись `Distinction` (4 поля); **три аспекта ОДНОГО акта** (зерно E/R/R: что / как / почему); со-конституция (обе стороны A и ¬A — из одного акта, `co_constitution`); асимметрия **`positive → ¬negative`** (L4, самозаземление).
- ✓

### 1.3 L1–L5 как теоремы различения ✓
- Законы онтологически первичны (свойства Логики, **со-даны с бытием**); в формализме мы их **прослеживаем** как теоремы записи `Distinction` (не «они рождаются из акта»).
- **Двойная нумерация** (онтологические имена ↔ формальные L1–L5):
  - L1 Тождество — `L1_stability` — *A есть A*.
  - L2 Непротиворечие — `L2_exclusivity` — **¬(A ∧ ¬A)**.
  - L3 Исключённое третье — `L3_totality` (= `classic`) — **A ∨ ¬A**. ⚠ единственная несущая **аксиома** ветви.
  - L4 Достаточное основание — `L4_self_grounding` (`positive → ¬negative`) — опора позитивности.
  - L5 Порядок / иерархия — `L5_hierarchy` (слой `Level`, `level_lt_irrefl`).
- Капстоун **`five_laws_from_distinction`** (все пять — из одного акта).
- ✓ *(L3 честно помечается как единственная аксиома)*

### 1.4 P1–P4 из законов ✓⚠ *(первый звон границы)*
- Четыре принципа существования следуют из пяти законов; **P1–P3 — теоремы, P4 — честно ПО ТИПОВОЙ КОНСТРУКЦИИ** (не чистый вывод).
  - P1 нет само-членства — `P1_from_L1_L5` / `P1_blocks_russell` (**Рассел становится невозможен**, а не «растворяется»).
  - P2 критерий прежде системы — `P2_from_L5` / `P2_no_circularity`.
  - P3 интенсиональная идентичность — `P3_from_L1_L4`.
  - P4 конечная актуальность ⚠ — обеспечена выбором `nat→Q` (по L5-секвенциальности); конструктивное содержание — в `L4_witness`; `P4_no_completed_infinity` (каждое Q = n#d). ← **ПЕРВЫЙ ЗВОН границы H1/P4.**
- Капстоун **`four_principles_from_five_laws`**.
- ✓⚠

### 1.5 E/R/R как конец цепи ✓
- **Три аспекта ОДНОГО акта, не три части.**
- Триада **Elements / Roles / Rules**; эпистемический порядок E→R→R ↔ генеративный **Rules→Roles→Elements**.
- Запись `FunctionalSystem` + экстракторы `get_Elements/Roles/Rules`.
- Следствие для чисел: **ℕ от 1** (из 1.2).
- **Переход:** цепь дала ОБЪЕКТ (`FunctionalSystem`) → Блок 2 разбирает его изнутри.
- ✓

## Две ноты (обе уже здесь, в Блоке 1)
- **M1 / позитивная онтология (с чего НАЧИНАЕМ):** всё от положительной единицы; ноль/отрицание производны. Якорь `one_distinction_exists` vs `zero_distinctions`. Звучит в 1.1 (старт) и точно в 1.2 (единица-как-число). Даже нумерация блоков — от 1.
- **H1/P4 (где УПИРАЕМСЯ):** первый звон в 1.4 (P4 по типовой конструкции); кульминирует в Блоке 7. Честный флагман: **граница финитизации = граница конститутивности**.
- Обе — **одна асимметрия L4** (самозаземление `positive → ¬negative`): сторона старта и сторона предела.

## Стиль и честность (правила голоса для этой главы)
- **Выводим и показываем:** логические формулы (`A=∃`, `¬∃→∃`, `¬(A∧¬A)`, `A∨¬A`, `positive→¬negative`) — в тексте; Coq-имена / Qed / `Print Assumptions` — в **Аппендикс**, не в постраничные сноски. Внутри раздела: сначала вывод/показ → затем результаты (значение, следствия, онтологическое чтение).
- **Вести от того, ЧТО ЕСТЬ;** не нагромождать «не». Законы со-даны с бытием — мы их **выводим / прослеживаем**.
- **Парадоксы не «растворяются»** — при хорошей форме (P1) они **невозможны**.
- **Честно:** L3 — единственная аксиома ветви; **P4 — по типовой конструкции (⚠)**, конструктив в `L4_witness`; не выдавать P4 за чистый вывод.
