# Блок 5 — ЦЕЛОЕ СВЕРХ ЧАСТЕЙ: эмерджентность (план главы, ключевые идеи)

## Роль и форма блока
- **Роль:** под-теория эмерджентности + исчисление соединения ярусов.
- **Тезис:** **эмерджентность = свойство целого ВНЕ образа карты часть→целое**; измерима, таксономизирована.
- **E/R/R-линза:** эмерджентность живёт на ярусе **Roles**; соединение — СВОЯ операция на каждом ярусе.
- **Вход из Блока 4:** одна система во времени. **Выход в Блок 6:** горизонталь (соединение) разобрана → вертикаль (башня уровней).

## Спина: 5.1 → 5.5

### 5.1 Свойство и наблюдаемое первоклассны ✓
- `Property L := FunctionalSystem L → Prop`; `Observable L V := FunctionalSystem L → V`.
- **`system_has_essence`** (существование → суть → познаваемо): всякая система удовлетворяет собственной конституции (через `fs_functional`) — реализованная **познаваемость**, 0-ax (мост к Эпистемологии, Книга III).
- **Карта часть→целое** = `prod_rel`; `part_reducible := separable`.
- ✓

### 5.2 Эмерджентность = свойство целого ВНЕ образа карты ✓★
- **`emergent := ~ separable`**: свойство целого, которого НЕТ в образе карты часть→целое.
- Это **общая таксономия**; запутанность — частный инстанс (5.4).
- ✓★

### 5.3 Таксономия + мера ✓⚠
- **Четыре страты** (каждая инхабитирована): `reducible` (= произведение, в образе) / `super_additive` (целое относит БОЛЬШЕ = коллективная эмерджентность) / `sub_additive` (целое относит МЕНЬШЕ = корреляция/ограничение) / `non_separable` (запутанность).
- **Мера на ℚ-амплитудах:** `q_det` (детерминант) = рациональная конкурренция; sound+complete детектор; **оптимум/экстремум = role-limit**.
- ⚠ Исчерпываемость родов НЕ заявлена (нужна разрешимость/classic).
- ✓⚠

### 5.4 Запутанность: инстанс + ℚ-мера + моноидальность/дагер + дуальность ✓⚠
- Запутанность = композит, **НЕ категорное произведение**; Bell/GHZ-чётность (`parity_roles`) — инстанс; `separable ⟺ is-a-product`.
- **ℚ-мера:** `q_det` (= конкурренция до нормировки); sound+complete (`det ≠ 0 ⟺ не факторизуемо`); рационален и сепаратор, и его значение; ⚠ только **экстремум** (1/√2 амплитуды, Цирельсон 2√2) = role-limit.
- **Моноидальность/дагер:** симметрично-моноидальная (⊗-бифунктор / единица / симметрия) + dagger на амплитудах; **нет запутанных СОСТОЯНИЙ на реляционном ярусе** (состояние = пара ⟹ запутанность в Roles/амплитудах — локализует стену). ⚠ стена = dagger-compact (√2/Гильберт).
- **Дуальность (категорное замыкание):** **произведение разделимо ↔ сумма кросс-эмерджентна**.
- ✓⚠

### 5.5 Исчисление соединения ярусов ✓
- Каждый ярус — СВОЯ операция возрастающей связанности: **Elements свободно** (×, безусловно) / **Roles встреча + эмерджентность** (`rcomp`; `roles_super_additive`) / **Rules гейт-решётка** (`cstronger`/`cmeet`; составимые Rules = под-решётка).
- = **операционный смысл ранговой асимметрии** (2.4): свободно < встреча < гейт.
- ⚠ Конкретные свидетели, без полноты решётки.
- ✓

→ *Соединение по горизонтали разобрано — Блок 6 идёт по ВЕРТИКАЛИ уровней (башня).*

## Честность (правила голоса)
- Эмерджентность — **структурна** (свойство вне образа карты); запутанность — инстанс, не отдельная сущность.
- ℚ-мера: рациональны и сепаратор, и значение; ⚠ только **экстремум** = role-limit (1/√2, Цирельсон 2√2 — цитируются, не пере-доказываются).
- Моноидальность — **скелет** (без пентагона/компактности); дагер-компактность = ⚠ стена √2/Гильберт.
- Таксономия — ⚠ без заявления исчерпываемости.
