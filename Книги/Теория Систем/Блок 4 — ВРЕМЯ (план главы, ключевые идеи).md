# Блок 4 — ВРЕМЯ: система, как она живёт (план главы, ключевые идеи)

## Роль и форма блока
- **Роль:** под-теория динамики — «система, как она ЖИВЁТ».
- **Тезис:** **необратима РОВНО одна стрела — и это L5.**
- **E/R/R-линза:** **`InsideOperator` = эндо-морфизм** (сохраняет Roles); время = итерация под Rules.
- **Вход из Блока 3:** статичный объект-категория. **Выход в Блок 5:** одна система во времени → много систем как целое.

## Спина: 4.1 → 4.5

### 4.1 Оператор (внутри / вне) и эволюция ✓
- **`InsideOperator S := ERRMorphism S S`** (эндо — система преобразует собственное состояние); множество эндо = **моноид** (id + ассоциативность).
- **`OutsideOperator S := {S' & ERRMorphism S' S}`** (действие из ДРУГОЙ системы S' через сцепку); **внутри ⊂ вне** (само-сцепка) — «оператор внутри другой системы, которая производит взаимодействие».
- Эволюция: `evolve` / `trajectory` / `equilibrium` / `reversible`; примеры `flip` / `collapse` / `SB`.
- ✓

### 4.2 Две стрелы ✓★
- **Состояние возвратимо** (орбита замыкается) ↔ **L5-стрела времени НЕОБРАТИМА** (`arrow_never_returns`).
- Это и есть тезис блока: из всей динамики необратима ровно одна стрела — **L5** (стрела порядка/времени), а не движение состояния.
- **Аттрактор = role-limit** (ℚ: `halve`→0 ограничен / `double` убегает) — первый звон H1 (раскрыт в 4.5).
- ✓★

### 4.3 Группа, ℕ-действие, бассейн ✓
- **Обратимые операторы ⇒ степени обратимы** (групповая структура).
- `evolve` = **ℕ-действие** (`evolve_add`); **`return_times` = под-моноид ℕ** (flip→чётные, collapse→все, shift→только 0).
- **Бассейн достижимости** `reaches`: `halve` достигает 0 **только из 0** (приближается, не приходит) — role-limit-вкус.
- ✓

### 4.4 Сопряжённость, инварианты, Ляпунов ✓
- **Сопряжённость** (бий + интертвайн) = отношение эквивалентности; сохраняет equilibrium/период; **`flip ≁ collapse`** (неподвижная точка — инвариант).
- **Инвариантные множества = РЕШЁТКА** (∩/∪/full/empty); `reachable` = наименьшее инвариантное, содержащее старт; рестрикция коммутирует.
- **Функции Ляпунова:** невозрастающая ⇒ ограничена/регулярна; **строгая ⇒ не-равновесие никогда не возвращается** (`collapse` — пример).
- ✓

### 4.5 Аттрактор = role-limit ◇ *(звон H1 в динамике)*
- ◇ **Аттрактор — это role-limit:** траектория ПРИБЛИЖАЕТСЯ к пределу, но финитно его не достигает (½ⁿ→0, но каждое ½ⁿ > 0). Динамическая грань границы H1/P4.
- **Мост к Блоку 7:** та же граница, что вырезать/слить ((ко)эквалайзеры 3.6) и незавершённая башня уровней (6.2).

→ *Одна система во времени разобрана — Блок 5 берёт МНОГО систем как целое (эмерджентность).*

## Честность (правила голоса)
- Необратима **ровно одна** стрела (L5); движение состояния обратимо/возвратимо — не путать.
- Аттрактор = **role-limit** (◇ наблюдение, динамическая грань H1): приближается, не приходит.
- `halve` «достигает 0 только из 0» — конечно-актуальная сторона; предел 0 — role-limit.

## Аппендикс A — формальные якоря Блока 4 *(волна F + оператор волны D; 0 ax сверх `classic`=L3)*

- `ERRDynamics` — `InsideOperator`, `evolve`/`trajectory`/`equilibrium`/`reversible`; `flip`/`collapse`/`SB`.
- `ERRDynamicsArrow` — ★ `arrow_never_returns` (L5-стрела); аттрактор = role-limit (`halve`/`double`).
