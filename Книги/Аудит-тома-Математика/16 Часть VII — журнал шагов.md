## Шаг 1. Ортонормированные системы с выполнимой посылкой и ошибка ряда Фурье (18.11.2026)

Места 1.1, 1.2 (VII.1), 4.1, 4.3 (VII.4), 5.4 (VII.5).

### Что расходилось

Бессель, Пифагор, наилучшее приближение с единственностью, критерий Парсеваля (VII.1) и вся конечная теория
усечений — тождество ошибки, монотонность, критерий нуля (VII.4) — названы доказанными, но стоят в разделах `ON`
под посылкой «ортонормированность при всех номерах i, j», на N координатах невыполнимой
(`on_all_indices_unsat`). Свидетель (3, 4) был вычислением 25 = 25, к критерию не привязанным. Сноски VII.4
называли связь лемм неточно: неотрицательность ошибки «эквивалентна» Бесселю; критерий нуля «опирается на»
критерий полноты.

### Разбор E/R/R нового файла `src/process/ProcessOrthonormalFourier.v`

- **Элементы.** Векторы с N рациональными координатами; семейство e; конечные суммы; коэффициенты ⟨e_k, f⟩;
  число K снятых направлений.
- **Роли.** `seq_inner` — спаривание; ортонормированная система — первые K0 векторов e (выполнимая посылка
  `ProcessL2Orthonormal.v`); частичная сумма P_K; `ferr e f N K` — квадрат ошибки ‖f − P_K‖² как функция стадии
  K процесса усечений; `captured c K` — энергия первых K коэффициентов.
- **Правила.** Спаривание билинейно и симметрично; остаток ортогонален снятым направлениям; ошибка = полная
  энергия − захваченная; очередной коэффициент уменьшает ошибку ровно на свой квадрат; N ортонормированных
  векторов на N координатах восстанавливают всякий вектор.
- **Проверка по P4.** K пробегает действительно данные векторы (K ≤ K0 ≤ N); при фиксированном N процесс
  усечений имеет конечное число стадий и кончается точным восстановлением при K = N. О завершённом бесконечном
  базисе ничего не утверждается; переход N → ∞ — отдельный процесс (шаг 5).
- **Не утверждается.** Сходимость при нефиксированном усечении N; существование ортонормированных систем сверх
  предъявленных примеров; тригонометрическая система; корневая ошибка ‖f − P_K‖.

### Что расходилось

Страницы говорили: нормированная система Уолша удовлетворяет `Hon`; в общем случае нормировка вводится
«абстрактным параметром s с условием s² = N»; на системе Уолша «буквально выполняется вся теория Главы 7.1». В
формализации параметра нормировки для общего N нет; рационального s с s² = N при нечётном k не существует;
теоремы Главы 7.1 требуют нормы 1 и к строкам Уолша (норма в квадрате N) не применялись.

### Разбор E/R/R нового файла `src/process/ProcessOrthogonalWalsh.v`

- **Элементы.** Векторы с N рациональными координатами; семейство e; квадраты норм d_k > 0 первых K0 векторов;
  строки ±1 матрицы Адамара размера N = 2^k; конечные суммы.
- **Роли.** Ортогональная система — первые K0 векторов попарно ортогональны, ⟨e_k, e_k⟩ = d_k (ни один вектор
  не делится на корень); `og_coef k` — коэффициент Фурье ⟨e_k, f⟩ / d_k; частичная сумма P_K; `walsh_n k s` —
  строки Уолша, делённые на рациональное s с s² = N, когда такое s дано.
- **Правила.** Теория ортонормированной системы верна для ортогональной с весами d_k: тождество остатка,
  Бессель, наилучшее приближение с единственностью, Парсеваль как критерий полноты. В наблюдаемых величинах
  стоит d_k = N, а не √N.
- **Проверка по P4.** Все суммы конечны; на корень ничего не делится: где классический текст нормирует на
  1/√N, коэффициент делится на рациональное N. Корень √N при нечётном k — процесс и не используется; что он
  не рациональное число — теорема.
- **Не утверждается.** Ортонормированная система Уолша над ℚ при нечётном k; корень √N как число;
  секвентный порядок строк; что-либо о бесконечном числе координат.

## Шаг 3. Вентиль Адамара над ℚ[√2] (18.11.2026)

Место 2.1 (VII.2: стр. 37–39, 222–234; сноски 8, 9).

### Что расходилось

Страница говорила: нормировка 1/√2 вынесена «в абстрактный параметр s с соотношением s²·2 = 1», и две черты
вентиля (инволюция, суперпозиция) «доказаны как рациональные факты». В `ProcessHadamardGate.v` параметр
`s2inv` имеет тип ℚ, а рационального числа с таким соотношением нет: теорема `hgate_involution` примеров не
имеет, и ни при каком рациональном множителе вентиль не инволюция.

### Разбор E/R/R нового файла `src/process/ProcessHadamardGateSqrt2.v`

- **Элементы.** Рациональные амплитуды; амплитуды из ℚ[√2] — пары (a, b) рациональных, читаемые как a + b√2
  (`CliffordField.RQ`); элементы ±1 матрицы Адамара размера 2.
- **Роли.** `hgate s` — вентиль с рациональным множителем s (`ProcessHadamardGate.v`); `hgateR` — вентиль с
  множителем 1/√2 = (0, 1/2), элементом ℚ[√2]; `e0R` — базисное состояние |0⟩.
- **Правила.** Над ℚ квадрат вентиля с множителем s есть умножение на 2s², а 2s² = 1 рационального решения не
  имеет; над ℚ[√2] соотношение s²·2 = 1 выполнено, и вентиль — инволюция и изометрия. Наблюдаемая величина —
  квадрат амплитуды 1/2 — рациональна.
- **Проверка по P4.** √2 входит как элемент расширенного носителя: пара рациональных с точной арифметикой; ни

## Шаг 5. Сходимость ряда Фурье по стандартной системе (18.11.2026)

Место 4.2 (VII.4: стр. 43–44, 110–115, сноска 2).

### Что расходилось

Глава называла Рисса — Фишера «мостом к носителю предела» и «L²-полнотой по построению». Теорема
`l2_riesz_fischer` верна при фиксированном усечении N (страница этого не оговаривала), её заключение после
развёртывания `l2_limit` совпадает с посылкой, и к частичным суммам ряда Фурье она применена не была: ни для
одной системы не было доказано, что частичные суммы образуют процесс Коши и что предел есть f.

### Разбор E/R/R нового файла `src/process/ProcessFourierConvergenceStd.v`

- **Элементы.** Последовательность f рациональных координат; усечение N (число читаемых координат); число K
  членов частичной суммы; конечные суммы.
- **Роли.** `captured f n` — процесс энергии n ↦ Σ_{i<n} f_i²; `ferr delta f N K` — квадрат ошибки K-членной

  сумм; `l2_limit` — покоординатный предел из `ProcessL2RieszFischer.v`.
- **Правила.** При K ≤ N ошибка есть энергия между K и N, при N ≤ K — нуль. Поэтому ошибка мала при всех
  усечениях N сразу в точности тогда, когда процесс энергии есть процесс Коши.
- **Проверка по P4.** Ничего не суммируется до бесконечности. «Ряд сходится» читается так: для всякого ε есть
  стадия M, после которой ошибка меньше ε при всяком усечении N, — утверждение о конечных суммах. Посылка
  «процесс энергии — процесс Коши» честная: из ограниченности она не выводится (нужна была бы классическая
  логика).
- **Не утверждается.** Сходимость для произвольной ортонормированной системы; что у всякой f с ограниченной
  энергией процесс энергии — процесс Коши; поточечная сходимость, явление Гиббса, тригонометрические ряды.
