## Итог простыми словами

1. **Цена названа почти везде верно.** Из 815 записей о Части V расхождение по цене — в шести, все — остатки
   прежней редакции. Действительная картина: метрика, топология, производная, интеграл, основная теорема,
   ступенчатый Фубини — без допущений; Гейне — Борель — без допущений; Больцано — Вейерштрасс — на `classic` и
   `L4_witness`; теорема об экстремуме — на `classic`; две теоремы о монотонных процессах — на `classic`.
2. **Главный вид расхождения — слова сильнее доказанного.** Расхождений 68. В 38 из них формализацию можно довести
   до слов главы без аксиом — наброски проверены компилятором; в остальных 30 правятся слова (из них в шести
   довести нельзя по существу: утверждение неверно, и это тоже проверено).
3. **Три крупные находки, где формализация может шагнуть вперёд:**
   - **Теорема об экстремуме доказуема без допущений.** `classic` входит в одну лемму — поиск ячейки сетки, а этот
     шаг вычислим. Полная цепочка до теоремы с мажорантой собрана: «Closed under the global context».
   - **Основная теорема анализа как сходимость процесса.** Сейчас доказан один уровень сетки на каждую точность;
     недостающая теорема («начиная с некоторого уровня» и эквивалентность процесса сумм постоянному приращению)
     набросана двумя помощниками независимо, без допущений. На неё опираются слова сразу двух глав (V.5 и V.6).
   - **Полнота пространства классов.** Глава V.1 честно называет её открытой; набросок доказательства собран: для
     регулярных представителей — без допущений, для произвольных — на одном `L4_witness`.
4. **Повторяющиеся виды:**
   - теоремы-вывески `…_is_process_construction` — в `src/process` их двенадцать, пять стоят в этой части (BW, EVT,
     производная, интеграл, основная теорема): заключение либо не упоминает предмет теоремы, либо верно по
     определению;
   - «темпы сходимости», вписанные числом (`bw_`, `evt_`, `deriv_`, `integral_`, `ftc_convergence_rate := 1 # 2`), с
     процессом не связанные;
   - одна доказанная сторона при словах «равносильно» (непрерывность через прообраз — дважды);
   - опущенные условия (неотрицательный шаг, отрезок [0, 1], условие `Proper`, знак коэффициента);
   - числа из устаревших шапок файлов.
