# Аудит тома «Математика». Часть III «От натуральных к рациональным» — отчёт первой вычитки

Дата первой вычитки: 13.11.2026 (вместе с Частью II). Состояние формализации: коммит `2c6fa49`.
Шаги по этой Части начнутся после закрытия таблицы Части II; журнал шагов будет заведён тогда же.

## Итог простыми словами

Четыре главы (от 984 до 1233 строк). Из 215 утверждений о формализации сходятся 188. Расходятся 27 записей —
это **14 мест**. Слова о цене в главах III.1–III.3 компилятор подтверждает везде («13 лемм, 0 аксиом»,
«без единой аксиомы», «без закона исключённого третьего»); в III.4 два места о цене устарели.

Главное:

- **Биекция ℕ ↔ ℚ** (III.2, III.3): доказаны два круговых обхода, а утверждения «равные дроби получают один
  номер» в файле нет, и из двух обходов оно не следует. Сам факт верен; не хватает восьми утверждений, набросок
  собран без аксиом.
- **Правило знаков** (III.1): названо выведенным из повторения смещения и двух разворотов; в коде умножение
  задано формулой, которая правило уже содержит. Доводится: умножение как повторение, правило из двойного
  разворота.
- **Процессы для √2** (III.4): «процесс сжимающихся интервалов, задающий √2, есть процесс Коши — доказанно» —
  такого процесса в формализации нет; предиката `sqrt2_process` в описанном виде нет. Доводится: процесс
  деления пополам, оценки для ньютонова и цепно-дробного процессов, их эквивалентность.
- **Деление на нуль** (III.2): «формальная запись не допускает устройством типа» — типом исключён только
  нулевой знаменатель; операция деления библиотеки определена всюду (`1 / 0 = 0`).
