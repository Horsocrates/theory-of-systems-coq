**В чём расхождение.** Общая формула «законы выведены как теоремы о свойствах записи» шире того, что есть в файле:
шагом вывода из записи получен один закон ($L4$), два закона для сторон записи даны её полями, один есть правило

**(а) Довести формализацию.** Сделать $L2$ и $L3$ для сторон записи выводимыми не из полей нельзя: поля
независимы, и без каждого из них соответствующее утверждение опровержимо. Проверено (`Check.v`, оба ответа —
Closed under the global context):

```coq
Record NoExcl := mkNoExcl { ne_pos : Prop; ne_neg : Prop; ne_exh : ne_pos \/ ne_neg }.
Lemma L2_fails_without_exclusive : ~ (forall D : NoExcl, ~ (ne_pos D /\ ne_neg D)).
Proof. intro H. apply (H (mkNoExcl True True (or_introl I))). split; exact I. Qed.

Record NoExh := mkNoExh { nx_pos : Prop; nx_neg : Prop; nx_excl : ~ (nx_pos /\ nx_neg) }.
Lemma L3_fails_without_exhaustive : ~ (forall D : NoExh, nx_pos D \/ nx_neg D).
Proof. intro H. destruct (H (mkNoExh False False (fun h => proj1 h))) as [f | f]; exact f. Qed.
```

Что можно добавить без аксиом, чтобы в файле были утверждения, которые из записи действительно выводятся и
требуют обоих полей (`Check.v`, Closed under the global context):

```coq
Theorem sides_codetermined : forall D : Distinction,
  (negative D <-> ~ positive D) /\ (positive D <-> ~ negative D).
Proof.
  intro D. split; split.
  - intros n p. exact (exclusive D (conj p n)).
  - intro np. destruct (exhaustive D) as [p | n]; [ contradiction | exact n ].
  - intros p n. exact (exclusive D (conj p n)).
  - intro nn. destruct (exhaustive D) as [p | n]; [ exact p | contradiction ].
Qed.
```

Каждая сторона завершённого различения есть отрицание другой. Ни из одного поля в отдельности это не следует
(пробные `codetermination_needs_exclusive`, `codetermination_needs_exhaustive`, Closed). Вторая возможная
добавка — теорема о том, где входит аксиома, — приведена в расхождении 3. Для $L5$ вывести что-либо из записи
нельзя: уровня в записи нет (расхождение 9).

```coq
Lemma identity_any_term :

Proof. intros T f g x. split; reflexivity. Qed.
```

## Расхождение 3. `L3_independence`: посылка не используется, равносильности нет (стр. 118, 576–603)

**Было:**

> (118) $L3$ имеет три формы — общую через аксиому `classic`, структурную через поле `exhaustive` и теорему
> равносильности `L3_independence`.
>
> (576–577) **Равносильность `classic` и $L3$-через-различение: `L3_independence`.**
>
> (588–592) Вместе с `L3_from_distinction`, дающей обратное направление, это показывает, что $L3$-через-различение и
> `classic` *равносильны по силе* — то же самое тождество `classic` $=$ $L3$, проведённое теперь в обе стороны.
>
> (601–603) Теорема фиксирует внутренне доступную часть: точное совпадение $L3$-через-различение и `classic`.

**Проверка.** `src/foundation/LawsFromDistinction.v:172`:

```coq
Theorem L3_independence : (forall D : Distinction, positive D \/ negative D)
                          -> (forall P : Prop, P \/ ~ P).
Proof.
  intros _ P. exact (classic P).
Qed.
```

`Print Assumptions L3_independence`: `Axioms: classic : forall P : Prop, P \/ ~ P`. Посылка отброшена (`intros _`),
заключение взято из аксиомы. Посылка — в точности утверждение `L3_from_distinction` (`:67`), которое закрыто без
аксиом: оно читается из поля. Заключение без аксиомы в CIC недоказуемо. Следовательно, импликация не может быть
доказана без `classic` и ничего не говорит о равной силе сторон: одна сторона — теорема без допущений, другая —
аксиома. Проверено (`Check.v`, Closed under the global context): всё утверждение теоремы равносильно самому
исключённому третьему.

```coq
Theorem L3_independence_statement_iff_EM :
  ((forall D : Distinction, positive D \/ negative D) -> (forall P : Prop, P \/ ~ P))
  <-> (forall P : Prop, P \/ ~ P).
Proof.
  split.
  - intro H. apply H. intro D. exact (exhaustive D).
  - intros EM _. exact EM.
Qed.
```

Оговорка главы на стр. 596–601 (теорема не доказывает метатеоретического тезиса о независимости) верна.

**В чём расхождение.** Теорема названа равносильностью и «точным совпадением», а доказывает импликацию, в которой
посылка не работает; исключённое третье для уже построенных различений и исключённое третье для всех пропозиций
по силе различны.

**(а) Довести формализацию.** Возможно, без аксиом. Аксиома входит не в утверждение о готовых различениях, а в
существование различения для произвольной пропозиции — это глава говорит на стр. 566–574. Это и есть двусторонняя
связь, и она доказуема без допущений (`Check.v`; оба ответа — Closed under the global context):

```coq
(* в целом: у всякой пропозиции есть каноническое различение  <->  исключённое третье *)
Theorem distinction_for_every_prop_iff_EM :
  (forall P : Prop, exists D : Distinction, positive D = P /\ negative D = (~ P))
  <-> (forall P : Prop, P \/ ~ P).
Proof.
  split.
  - intros H P. destruct (H P) as [D [Hp Hn]].
    pose proof (exhaustive D) as E. rewrite Hp, Hn in E. exact E.
  - intros EM P.
    exists (mkDistinction P (~ P)
              (fun H0 => match H0 with conj p np => np p end) (EM P)).
    split; reflexivity.
Qed.

(* поточечно: у P есть завершённое различение  <->  P решена *)
Theorem decided_iff_has_distinction : forall P : Prop,
  (P \/ ~ P) <-> (exists D : Distinction, positive D <-> P).
Proof.
  intro P. split.
  - intro H.
    exists (mkDistinction P (~ P)
              (fun H0 => match H0 with conj p np => np p end) H).
    simpl. split; intro p; exact p.
  - intros [D HD]. destruct (exhaustive D) as [p | n].
    + left. apply HD. exact p.
    + right. intro p. apply (exclusive D).
      split; [ apply HD; exact p | exact n ].
Qed.
```

Место — `LawsFromDistinction.v`, новых подключений не нужно. `L3_independence` другими файлами не используется

**(б) Поправить слова.**

отдельно определённом типе, и с записью формально не связан.

**(а) Довести формализацию.** Одной теоремой не доводится: нужна новая конструкция, связывающая различение с
уровнем (например, объект «различение на уровне» или порядок, получаемый из вложенности различений), — это решение
об устройстве формализации, а не пропущенная лемма. Набросок не делался.

**(б) Поправить слова.**

> (1240–1246) **Пять законов работают в одной формализации.** Запись `Distinction` с четырьмя полями и тип `Level`
> с оператором порядка — две части одной формализации, в которых все пять законов получают свои формальные
> представления: законы одного акта — на записи, закон порядка — на типе уровней. Это означает: законы одного акта
> *читаются* из одной и той же записи под разными углами зрения; закон порядка читается из иерархии уровней, на
> которых акты совершаются.
>
> (1291–1298) Совокупность теорем `LawsFromDistinction.v` показывает иное — что простейший формализуемый объект
> (запись `Distinction`) уже несёт в себе законы одного акта различения как свои *структурные свойства*,
> доступные для машинной проверки, а закон порядка столь же прямо читается из типа `Level`. Это — формальное
> свидетельство того, насколько глубоко работа Логики встроена в саму возможность определённого существования:
> даже минимальная формальная запись акта различения недостаточна, чтобы скрыть какой-либо из законов одного
> акта, — все они проявляются в ней неустранимо.

## Расхождение 10. Цена блока $L3 + L4$ (стр. 1226, 1228–1232)

**Было:**

> (1226) …Это — структурное условие *полноты разделения*, в котором появляется зависимость от аксиомы `classic`
> (через `exhaustive`).
>
> (1228–1231) Парные объединения, таким образом, не дублируют общую пятёрку, а *структурируют* её на два уровня:
> первичные конструктивные условия ($L1, L2$) и условия, требующие классической аксиомы ($L3, L4$ в полной форме).

**Проверка.** `Print Assumptions L3_L4_combined`: Closed under the global context. Доказательство (`:190–194`):
`exact (exhaustive D)` и `exact (L4_self_grounding D)`. Поле `exhaustive D` — данное записи; обращения к аксиоме в
теореме нет. `classic` входит в `distinction_of` (`Distinction.v:75`) и в общие формы: `Law_of_ExcludedMiddle`,
`L4_double_negation` (а также `L3_independence`, `laws_consistent`). Обе парные теоремы — части конъюнкции
`five_laws_from_distinction`.

**В чём расхождение.** Цена парной теоремы названа по смыслу поля, а не по компилятору: теорема закрыта без
аксиом. Граница «без аксиомы — с аксиомой» проходит не между двумя парами, а между структурными формами и общими
формами для произвольной пропозиции.

**(а) Довести формализацию.** Не требуется: ответ компилятора лучше заявленного.

**(б) Поправить слова.**

> (1226) Блок $L3 + L4$ — *полнота и обоснованность*. Между сторонами нет третьего, и наличие одной стороны
> обосновывает отсутствие другой. Это — структурное условие *полноты разделения*; сама парная теорема доказана
> без аксиом — исчерпанность берётся из поля `exhaustive`, — а зависимость от аксиомы `classic` появляется там,
> где различение строится для произвольной пропозиции (`distinction_of`).
>
> (1228–1232) Парные объединения, таким образом, не дублируют общую пятёрку, а *структурируют* её на два блока:
> определённость и несовместность ($L1, L2$) и полноту с обоснованностью ($L3, L4$). Обе парные теоремы
> конструктивны; классической аксиомы требуют общие формы для произвольной пропозиции — `Law_of_ExcludedMiddle` и
> `L4_double_negation`. $L5$ работает на отдельном уровне иерархии и в эти парные объединения не входит.

## Сомнительные места, расхождением не являющиеся

- **Блоки кода.** Инструмент отмечает три отличия от исходника. Два — в записи, не в утверждении: `classic`
  (стр. 476; `~ P` — `~P`) и `Law_of_SufficientReason` (стр. 752; в исходнике заключение в скобках). Третье —
  расхождение 6. Тексты доказательств на странице в двух местах записаны иначе, чем в исходнике, при тех же
  тактиках: `L4_double_negation` (стр. 800–802; гипотеза `Hnnp` — в исходнике `Hnn`), `L5_chain` (стр. 1009–1011;
  `split.` с двумя пунктами — в исходнике `split; [… | …]`).
- **`laws_consistent` (стр. 1162–1193, 1271–1283).** `Print Assumptions`: `Distinction.classic` — свидетелем взято
  `distinction_of True`. Цену страница не называет. Аксиома здесь не нужна (`Check.v`, Closed under the global
  context):

  ```coq
  Theorem laws_consistent_free : exists D : Distinction, positive D /\ ~ negative D.
  Proof.
    exists (mkDistinction True False (fun h => proj2 h) (or_introl I)).
    simpl. split; [ exact I | intro f; exact f ].
  Qed.
  ```

  Заменой свидетеля в `LawsFromDistinction.v:160` теорема о населённости записи становится свободной от
  допущений. Слова «нетривиальный формальный результат» (стр. 1179–1180) и «sanity check» (стр. 1278–1279) об
  одной теореме расходятся между собой; утверждение доказывается предъявлением одного экземпляра.
- **Стр. 294–298, «Доказательство содержит три тактики».** Третьей названа `Qed` — это команда завершения
  доказательства, не тактика; тактик две.
- **Стр. 316, 556, 758 и сноски 1–3, «вспомогательная лемма».** `L2_exclusivity`, `L3_totality`,
  `L4_self_grounding` объявлены в `Distinction.v` словом `Theorem`.
- **Стр. 356–358, «пришлось бы постулировать его отдельно или доказывать сложным образом».** Без поля `exclusive`
  утверждение опровержимо (экземпляр `True`, `True`), так что вторая возможность отсутствует; остаётся первая —
  вернуть поле. Того же рода, что расхождение 4, но без неверного утверждения об аксиоме.
- **Стр. 744–746, «две последние — классические следствия для произвольной пропозиции».** Из двух последних форм
  $L4$ на `classic` опирается одна; `L4_canonical` закрыта без аксиом, и глава сама называет её конструктивной
  (стр. 787–789). Слово «классические» здесь можно понять как «требующие классической логики».
- **Стр. 941 и стр. 999, 1014.** На стр. 941 сказано, что $L_1$ — «*не* атомарный уровень»; на стр. 999 и 1014
  он назван «атомарный уровень». К формализации не относится (в исходнике `L1` — «Logic = Foundation»,
  `TheoryOfSystems_Core_ERR.v:60`).
- **Стр. 479, 834, «две фундаментальные аксиомы».** Логических допущений в действии два, как и сказано. Для
  точности: `classic` объявлена в трёх местах (стандартная библиотека через `ToS_Axioms.v:31`,
  `foundation/Distinction.v:36`, `settheory/BorelDeterminacy.v:21`), а в разделе Навье — Стокса есть ещё две
  аксиомы и два параметра. Теоремы этой главы опираются на объявление из `Distinction.v`.
- **Стр. 484–486, «к этой аксиоме приложен комментарий».** Комментарий в `LawsFromDistinction.v:71–72` стоит после
  теоремы `L3_from_distinction`; аксиома объявлена в `Distinction.v:36`, и там рядом свой комментарий того же
  содержания (`:34–35`).
- **Стр. 508–515 и 651–654, «аксиома `classic` не *добавляет* ничего к структуре акта различения».** Глава
  разводит два уровня и относит эти слова к онтологии ToS; технический статус аксиомы назван на стр. 491–495. На
  формальном уровне аксиома — то, чем обеспечено существование различения для всякой пропозиции
  (`distinction_for_every_prop_iff_EM`, расхождение 3). Тезис автора не оценивается.
- **Стр. 723–726, «каждое поле `Distinction` обосновывается не извне, а через связь с другими полями».**
  Философское чтение; в формализации поля `exclusive` и `exhaustive` друг из друга не выводятся (расхождение 1),
  а в `distinction_of` поле `exhaustive` заполняется аксиомой.
- **Стр. 1248–1255, «Минимальность подтверждена. Каждый закон опирается на конкретное место структуры».**
  Соответствие «закон — место» не взаимно однозначно: $L2$ и $L4$ опираются на одно поле `exclusive`, $L1$ — не на
  поле. Теорем о минимальности в файлах главы нет; независимость двух полей-доказательств проверена пробным
  файлом. Оговорку о смысле минимальности глава даёт сама (стр. 1259–1269).
- **Стр. 78 и стр. 473.** «Формальные теоремы Главы 3 … не *постулируют* их» и «постулируется аксиома»: первое
  сказано об онтологическом статусе законов, второе — о технике; глава эти уровни разводит.
- **Стр. 974–975, «Иррефлексивность гарантирует, что иерархия — *строгая* структура, а не циклическая».** Циклы
  длины больше единицы исключает иррефлексивность вместе с транзитивностью; обе доказаны.
- **`laws_theorem_count` (стр. 113).** Число 22 вписано в определение рукой; со счётом теорем совпадает, но при
  добавлении теорем его нужно менять вручную.
- **Шапки исходников.** `LawsFromDistinction.v:6` — «STATUS: Qed, 0 Admitted, 0 new axioms» без числа;
  комментарии `:13–20` и `:71–72` («not an independent axiom», «L3 is not an EXTRA axiom») держат ту же формулу,
  что заглавие главы. При правке страницы их стоит привести к тому же виду.
