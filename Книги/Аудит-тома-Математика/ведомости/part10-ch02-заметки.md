Шаг первый — без допущений: вместо одной жёсткой оценки $1/m + 1/k$ годится любая *заданная* скорость сходимости
(функция `mu`, своя для каждого члена перечисления).

```coq

Definition modulus_for (R : RealProcess) (mu : nat -> nat) : Prop :=
  forall k a b : nat, (k > 0)%nat -> (a > mu k)%nat -> (b > mu k)%nat ->
    Qabs (R a - R b) <= 1 # Pos.of_nat k.

Definition valid_modulated_enumeration (E : Enumeration) (mu : nat -> nat -> nat) : Prop :=
  forall n, modulus_for (E n) (mu n) /\ (forall m, 0 <= E n m <= 1).

(** resampling along the modulus *)
Definition regularize (E : Enumeration) (mu : nat -> nat -> nat) : Enumeration :=
  fun n k => E n (S (mu n k)).

Lemma regularize_regular : forall E mu,
  valid_modulated_enumeration E mu -> valid_regular_enumeration (regularize E mu).

Lemma not_equiv_transfer : forall (D R : RealProcess) (mu : nat -> nat),
  is_Cauchy D -> modulus_for R mu ->
  not_equiv D (fun k => R (S (mu k))) -> not_equiv D R.

Theorem unit_interval_uncountable_modulated :
  forall (E : Enumeration) (mu : nat -> nat -> nat),
    valid_modulated_enumeration E mu ->
    exists D : RealProcess,
      is_Cauchy D /\ (forall m, 0 <= D m <= 1) /\ (forall n, not_equiv D (E n)).
Proof.
  intros E mu H.
  destruct (unit_interval_uncountable_trisect_v2 (regularize E mu)
              (regularize_regular E mu H)) as [D [HC [HU HN]]].
  exists D. split; [exact HC |]. split; [exact HU |].
  intro n.
  apply (not_equiv_transfer D (E n) (mu n) HC (proj1 (H n))).
  exact (HN n).
Qed.
```

Ход: каждый член перечисления пересчитывается по своей скорости в регулярный процесс (`regularize`), к новому
перечислению применяется теорема файла, а отделённость от пересчитанного процесса переносится на исходный
(`not_equiv_transfer`: зазор $\varepsilon$ превращается в $\varepsilon/2$). `Print Assumptions

(`regular_is_modulated`: регулярное перечисление имеет скорость `mu n k = 2 * k`; Closed under the global context).

## Расхождение 2. Доказательство `diagonal_differs` опирается не на инволютивность `flip` (сноска 3, стр. 175)

**Было:** «Используется только инволютивность `flip` (булева отрицания); **0 аксиом** — файл это печатает.»

**Проверка.** `src/ProcessDiagonal.v:85–91`:

```coq
Lemma diagonal_differs : forall f n, ~ bp_eq (diagonal f) (f n).
Proof.
  intros f n Heq.
  unfold bp_eq in Heq. specialize (Heq n).
  unfold diagonal in Heq.
  apply (flip_neq (f n n)). exact Heq.
Qed.
```

Применена лемма `flip_neq` (`:53`): `forall b, flip b <> b`. Лемма `flip_involutive` (`:48`: `flip (flip b) = b`) в
файле есть, но используется только в `flip_eq_iff` (`:64`), на которую диагональные теоремы не ссылаются. Одной
инволютивности для вывода недостаточно — проверено (`CheckDiag.v`, обе леммы — Closed under the global context):

```coq
(* what the proof uses *)
Lemma diag_from_no_fixed_point : forall g : bool -> bool,
  (forall b, g b <> b) ->
  forall (f : nat -> BinProcess) (n : nat), ~ bp_eq (fun k => g (f k k)) (f n).

(* involutivity alone is not enough: the identity is an involution *)
Lemma involution_alone_not_enough :
  exists g : bool -> bool,
    (forall b, g (g b) = b) /\
    exists f : nat -> BinProcess, bp_eq (fun k => g (f k k)) (f 0).
```

**В чём расхождение.** Диагональ работает потому, что переворот не оставляет на месте ни одно значение; сноска
называет другое свойство, которого для вывода мало. Цена («0 аксиом») названа верно.

**(а) Довести формализацию.** Не требуется: формализация верна, расходятся слова.

**(б) Поправить слова:**

> Используется только то, что `flip` (булево отрицание) не оставляет на месте ни одно значение (`flip_neq`:
> $\texttt{flip}\ b \neq b$); **0 аксиом** — файл это печатает.

## Сомнительные места (не расхождения)

- **Сноска 2 (стр. 174) и стр. 46, «биекция между ℕ и рациональными».** Точная опора этих слов — `Q_bijection`:
  `(forall n, index_of_Q (enum_Q n) = n) /\ (forall q, enum_Q (index_of_Q q) == q)`; в сноске названа только биекция
  для положительных пар (`Q_positive_countable`) и определение `enum_Q`. Предложение: дописать в сноску «свойства
  обхода всех рациональных — `Q_countable` и `Q_bijection`».
- **Стр. 46–51, биекция «с точностью до равенства дробей».** `enum_Q` выдаёт только несократимые дроби; дробь `2#4`
  как запись не получается, получается равная ей `1#2`. Теоремы сформулированы через `==` (равенство дробей) — это и
  есть рациональные числа; для чтения главы поправка не нужна.
- **Стр. 54–55, «уникальный номер».** Отдельных лемм «равным дробям — один номер» и «разным — разные» в файле нет; обе
  следуют из `Q_bijection`. Проверено (`CheckQ.v`, Closed under the global context): `index_of_Q_wd : q == q' ->
  index_of_Q q = index_of_Q q'`, `index_of_Q_inj : index_of_Q q = index_of_Q q' -> q == q'`, `enum_Q_inj : enum_Q n
  == enum_Q m -> n = m`. Вычислением: `enum_Q` от 0 до 6 — $0, 1, -1, 1/2, -1/2, 2, -2$; `index_of_Q (3#4) =
  index_of_Q (6#8) = 27`.
- **Стр. 107–109, «явным устойчивым зазором».** В доказательстве зазор держится при всех $m \ge \max(\texttt{trisect\_ref}\ n,\ n+1)$
  (`ShrinkingIntervals_ERR.v:3460–3501`). В формулировке теоремы стоит `not_equiv` (`:1109`): `exists eps, eps > 0 /\
  forall N, exists m, (m > N)%nat /\ Qabs (R1 m - R2 m) >= eps` — зазор встречается сколь угодно поздно, а не начиная
  с некоторого шага. Для двух процессов Коши первое следует из второго — проверено (`Check.v`, Closed under the global
  context): `not_equiv_stable_gap : is_Cauchy D -> is_Cauchy R -> not_equiv D R -> exists eps, eps > 0 /\ exists N,
  forall m, (m > N)%nat -> Qabs (D m - R m) >= eps`. Слова главы верны; лемму можно внести в файл, чтобы они имели
  прямую опору.
- **Стр. 110, 115–116, 120, 149, 157–158, 168–169, цена дихотомии названа «L3».** Компилятор называет два допущения:
  `Classical_Prop.classic` и `ToS_Axioms.L4_witness`. Полная цена стоит на стр. 32 («и извлечение свидетеля») и в
  сноске 1; в итоговых формулах она сокращена до «L3» и «классическая логика».
- **Стр. 168–169, «ровно … ни шагом больше».** Компилятор подтверждает распределение допущений: ядро — без них,
  дихотомия — с ними. Что дихотомия без `classic` недостижима, формализация не доказывает.
- **Стр. 27, «весь диагональный результат над $2^{ℕ}$».** Из 22 объявлений `ProcessDiagonal.v` 21 — Closed under the
  global context; одна лемма — `bp_eq_not_enum_witness` (`:208`) — стоит на `Classical_Prop.classic`. Она говорит не о
  диагонали, а о произвольной неперечислимой совокупности (для всякого `f` находит в ней непокрытый процесс), в главе
  не названа и вне своего файла не применяется.
- **Стр. 155–157, «правило-диагональ …, доводимое до утверждения об отрезке трисекцией».** Теорема об отрезке из
  `diagonal_differs` не выводится: `ShrinkingIntervals_ERR.v` файл `ProcessDiagonal.v` не подключает, доказательства
  независимы. Общее у них — приём (на шаге $n$ уйти от $n$-го члена перечисления).
- **Стр. 97–98, «её предел лежит в $[0,1]$».** Теорема даёт процесс Коши `D`, все значения которого лежат в $[0,1]$;
  рационального предела она не утверждает. В процессном чтении главы это одно и то же.
- **Стр. 30–32, «не более чем счётно».** `is_enumerable C` (`ProcessTypes.v:54`) — совокупность покрывается некоторым
  перечислением; члены перечисления не обязаны лежать в `C`, пустая и конечная совокупности включены. `is_closed C`
  (`ProcessContinuumHypothesis.v:44`) — `C` есть совокупность путей дерева, заданного функцией `list bool -> bool`.
  Формулировка подробно сверена в аудите Главы 4.5.
- **Стр. 37 и 120–121, «граница финитизации совпадает с границей конструктивности».** На стр. 37 и 120–121 сказано в
  изъявительном наклонении, на стр. 159 названо наблюдением. Теоремы с такой формулировкой глава не называет.
  Проверка расхождения 1 это наблюдение уточняет: когда скорость сходимости дана как конечное данное, допущений нет;
  когда известно лишь её существование, нужен $L4$.
