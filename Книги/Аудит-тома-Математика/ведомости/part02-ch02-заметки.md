## Расхождение 3. Содержательное чтение `succ_is_new_distinction` сильнее её утверждения (стр. 820–827)

**Было:**

> `succ_is_new_distinction` говорит: из реализуемости $n$ следует реализуемость $n + 1$. Доказательство прямое —
> взять список, реализующий $n$, и присоединить к нему ещё одно различие; наращённый список реализует $n + 1$.
> Содержательно теорема говорит то, что Глава II.1 назвала бы переходом к следующему числу: *следующее число
> есть нынешнее плюс ещё один совершённый акт*. Операция следования — не приписывание извне, а совершение
> нового различения.

**Проверка.** `src/foundation/PrimalityOfOne.v:84–91`:

```coq
Theorem succ_is_new_distinction : forall n,
  distinction_count_from_one n ->
  distinction_count_from_one (S n).
Proof.
  intros n [Ds [Hlen Hge]].
  exists (distinction_of True :: Ds).
  split; [simpl; lia | lia].
Qed.
```

`Print Assumptions`: `Axioms: Classical_Prop.classic`. Первые две фразы страницы точны. Но заключение теоремы
верно при всяком $n$ и без посылки (`Check.v`, Closed):

```coq
Theorem succ_conclusion_without_premise : forall n, distinction_count_from_one (S n).

Example premise_false_conclusion_true :
  ~ distinction_count_from_one 0 /\ distinction_count_from_one (S 0).
```

При $n = 0$ посылка ложна, заключение истинно. Утверждение говорит, что список длины $n + 1$ существует; какой
это список и как он связан со списком длины $n$, в утверждение не входит — под квантором существования годится
любой свидетель. Присоединение одного различия к прежнему списку есть ход доказательства (закрытого `Qed`).
Операцию `add_distinction` и теорему `add_distinction_increments` доказательство не применяет.

**В чём расхождение.** «Следующее число есть нынешнее плюс ещё один совершённый акт» — это то, что делает
доказательство, а не то, что утверждает теорема. Связь двух списков на уровне утверждения несёт только
`add_distinction_increments`, и только в одну сторону.

**(а) Довести формализацию.** Возможно, без аксиом — сказать о списках то, что глава говорит о числах, и в обе
стороны. Набросок проверен (`Check.v`, Closed under the global context):

```coq
(* Список реализует S n тогда и только тогда, когда он получен
   присоединением одного различия к списку, реализующему n. *)
Theorem succ_count_iff_one_more_act : forall (n : nat) (Ds : list Distinction),
  length Ds = S n <->
  exists (D : Distinction) (Ds' : list Distinction),
    Ds = add_distinction Ds' D /\ length Ds' = n.
Proof.
  intros n Ds. split.
  - destruct Ds as [| D Ds']; simpl; intro H.
    + discriminate.
    + exists D, Ds'. split; [ reflexivity | lia ].
  - intros [D [Ds' [HD Hl]]]. subst Ds. rewrite add_distinction_increments. lia.
Qed.
```

Эта теорема не имеет вырожденного случая: её заключение без посылки неверно, и она использует и определение
`add_distinction`, и теорему `add_distinction_increments`.

**(б) Поправить слова:**

> …наращённый список реализует $n + 1$. Содержательно это доказательство проводит то, что Глава II.1 назвала бы
> переходом к следующему числу: *следующее число есть нынешнее плюс ещё один совершённый акт*. Само утверждение
> теоремы скромнее её доказательства: оно говорит, что список длины $n + 1$ существует, и связи его со списком
> длины $n$ не удерживает. Операция следования — не приписывание извне, а совершение нового различения.

Если добавление (а) принято, вместо оговорки: «Эту связь удерживает теорема `succ_count_iff_one_more_act`:
список реализует $n + 1$ в точности тогда, когда он получен присоединением одного различия к списку,
реализующему $n$».

**(а) Довести формализацию.** Возможно, без аксиом; заодно получают опору слова стр. 772–774 («это не влияет на
длину») и чтение списка как стека. Набросок проверен (`Check.v`, Closed under the global context):

```coq
Definition snoc_distinction (Ds : list Distinction) (D : Distinction) := Ds ++ [D].

Theorem snoc_distinction_increments : forall Ds D,
  length (snoc_distinction Ds D) = S (length Ds).
Proof. intros Ds D. unfold snoc_distinction. apply last_length. Qed.

Theorem add_and_snoc_same_count : forall Ds D,
  length (add_distinction Ds D) = length (snoc_distinction Ds D).

(* хронологическое чтение получается обращением стека *)
Theorem snoc_is_reversed_add : forall Ds D,
  rev (add_distinction Ds D) = snoc_distinction (rev Ds) D.
Proof. intros Ds D. reflexivity. Qed.
```

**(б) Поправить слова:**

> Если же где-то понадобится хронологическое чтение слева направо, его даёт альтернативная операция
> присоединения в конец списка (`Ds ++ [D]`); кардинальный путь настоящей главы в ней не нуждается, поскольку
> опирается на длину, а не на направление порядка.

При принятом добавлении (а) в скобках вместо `Ds ++ [D]` ставится `snoc_distinction`.

## Сомнительные места (не расхождения)

1. **Цена, о которой страница не говорит (стр. 645–659, 735–742, 790–797, 811–818).** По компилятору
   `first_count_is_one`, `succ_is_new_distinction`, `positive_nat_is_distinction_count` (и леммы
   `one_distinction_exists`, `two_distinctions_exist`, `distinction_count_succ`, `distinction_count_any` в
   `Distinction.v`) стоят на `Classical_Prop.classic`. Причина одна — свидетель `distinction_of True`: каноническое
   различение строится с `classic P` (глава I.5, стр. 392–402 её страницы). Страница свидетеля называет
   (стр. 648, 655, 793–797), цену — нет; рядом стоят слова «не „число $n$ постулировано аксиомой“» (стр. 685).
   Аксиома здесь не нужна: страница I.2 сама говорит, что различение из `True` и `False` строится без
   классического принципа (стр. 1431–1434 её страницы). Со свидетелем `mkDistinction True False …` все три теоремы закрыты (`Check.v`:
   `first_count_is_one_closed`, `succ_is_new_distinction_closed`, `positive_nat_is_distinction_count_closed` —
   Closed under the global context; ход доказательств тот же). Два пути: (а) заменить свидетеля в
   `PrimalityOfOne.v` и `Distinction.v` — утверждения и имена не меняются, зависимых файлов нет; тогда на
   странице меняются блок кода стр. 645–650 и имя свидетеля на стр. 655, 793–797; (б) оставить формализацию и
   добавить на стр. 659 фразу: «Свидетель `distinction_of True` — каноническое различение, и по нему теорема
   наследует его цену, $L3$ (аксиома `classic`); различение со сторонами `True` и `False` дало бы тот же
   результат без неё». Это место записано в журнале Части I («Для Части II», шаг 3).
2. **Стр. 689–695, 726–733, 849–853: реализуемость и свойства различения.** Теорема
   `positive_nat_is_distinction_count` из свойств записи `Distinction` использует одно — что тип обитаем: список
   любой длины есть над любым обитаемым типом (`Check.v`, `list_of_any_length`, Closed). Слова «предикат мог бы
   оказаться выполнен лишь для некоторых чисел» (стр. 726–727) — риторический ход; формально предикат равносилен
   $1 \le n$ (`from_one_iff_positive`). Статус результата глава называет честно (стр. 855–870: «реализационный,
   а не типообразующий»).
3. **Стр. 1215–1222, мост `bridge`.** По определению мост ведёт на одну определённую стадию — нулевую
   (`forall n, S n -> actual 0 n`), тогда как страница говорит «на конечной стадии» и «на некоторой стадии».
   Для любой одной стадии противоречие то же (`Check.v`, `completed_inf_contradicts_P4_at_any_stage`, Closed);
   мост «каждый член актуален на своей стадии» с $P4$ совместим (`pointwise_bridge_is_compatible`, Closed) —
   это и есть различие, проведённое на стр. 1219–1222. Теорем с произвольной стадией в файле нет; их можно
   добавить.
4. **Стр. 1189–1190, 1196–1197, 1206–1208: «нет стадии, на которой был бы налично весь ряд».** В
   `P4CompletedInfinity.v` это доказано для одной модели стадий (четвёртый конъюнкт
