> Канонический коммутатор с $c=i\hbar\ne0$ *не реализуем* никакими конечными матрицами. Формально доказан случай
> рациональных матриц и рациональной постоянной $c$ (над ℚ, без аксиом); для мнимой постоянной тот же довод со
> следом применяется к вещественной и мнимой частям порознь.[^7]

не вмещает») опираются на ту же теорему; отдельной правки не требуют (в ведомости — ok со ссылкой на стр. 150).

## Расхождение 8. Свидетель сноски 7: вычислением проверен только нулевой след (стр. 286)

**Было:**

> (сноска 7) Конкретный свидетель: $[A,B]=\mathrm{diag}(1,-1)$, след $0$, не кратен $\mathbf{1}$.

**Проверка.** `src/process/ProcessCanonicalCommutator.v:148–154`:

```coq
(* Concrete 2×2 witness: A = [[0,1],[0,0]], B = [[0,0],[1,0]],
   [A,B] = AB − BA = [[1,0],[0,−1]] — NOT a multiple of I — and trace[A,B] = 0. *)
Example trace_commutator_concrete :
  let A := fun i j => if andb ((i =? 0)%nat) ((j =? 1)%nat) then 1 else 0 in
  let B := fun i j => if andb ((i =? 1)%nat) ((j =? 0)%nat) then 1 else 0 in
  mat_trace (mat_sub (mat_mul A B 2%nat) (mat_mul B A 2%nat)) 2%nat == 0.
```

Утверждение примера — только равенство следа нулю. Равенство $[A,B]=\mathrm{diag}(1,-1)$ и слова «не кратен
единичной» стоят в комментарии.

**В чём расхождение.** Из трёх свойств свидетеля компилятором проверено одно; два других названы в сноске наравне
с ним, а в файле записаны комментарием. Сами свойства верны.

**(а) Довести формализацию.** Доводится двумя примерами (проверено в `Check.v`, раздел 4а, Closed under the
global context):

```coq
Example commutator_concrete_entries :
  let A := fun i j => if andb ((i =? 0)%nat) ((j =? 1)%nat) then 1 else 0 in
  let B := fun i j => if andb ((i =? 1)%nat) ((j =? 0)%nat) then 1 else 0 in
  let C := mat_sub (mat_mul A B 2%nat) (mat_mul B A 2%nat) in
  C 0%nat 0%nat == 1 /\ C 0%nat 1%nat == 0 /\ C 1%nat 0%nat == 0 /\ C 1%nat 1%nat == - (1).
Proof. repeat split; vm_compute; reflexivity. Qed.

Example commutator_concrete_not_scalar :
  let A := … in let B := … in
  let C := mat_sub (mat_mul A B 2%nat) (mat_mul B A 2%nat) in
  forall c : Q, ~ (C 0%nat 0%nat == mat_scal c mat_id 0%nat 0%nat
                   /\ C 1%nat 1%nat == mat_scal c mat_id 1%nat 1%nat).
```

**(б) Поправить слова.**

> Конкретный свидетель: для $A=\bigl(\begin{smallmatrix}0&1\\0&0\end{smallmatrix}\bigr)$,
> $B=\bigl(\begin{smallmatrix}0&0\\1&0\end{smallmatrix}\bigr)$ след коммутатора равен $0$ (проверено вычислением);
> сам коммутатор — $\mathrm{diag}(1,-1)$, не кратен $\mathbf{1}$.

## Расхождение 9. «Обязаны быть неограниченными (бесконечномерными)»: доказано отсутствие конечномерной реализации (стр. 137, 140–142)

**Было:**

> (140–142) У него есть чисто алгебраическое следствие, объясняющее, *почему* $\hat q,\hat p$ обязаны быть
> неограниченными (бесконечномерными).

**Проверка.** `no_finite_ccr` (`ProcessCanonicalCommutator.v:125`) — о матрицах $N\times N$: конечномерной
реализации нет. Неограниченность — свойство операторов на бесконечномерном пространстве: в классической
математике это отдельная теорема (ограниченных операторов с $[A,B]=c\cdot\mathbf 1$, $c\ne0$, нет), и довод со
следом её не даёт — у ограниченного оператора в бесконечной размерности следа, вообще говоря, нет. Нормы
оператора на полных последовательностях в названных файлах нет; утверждения о неограниченности $\hat q$ или
$\hat p$ в них нет. Слово «неограниченны» стоит и в заголовке раздела (стр. 137), и в первой строке шапки файла
(«forces unbounded operators»).

**В чём расхождение.** Назван более сильный классический факт (неограниченность), а доказан более слабый
(бесконечномерность); скобка страницы их отождествляет.

**(а) Довести формализацию.** Общая теорема о неограниченности в нынешнем слое не доводится: нужна операторная
норма на бесконечномерном пространстве последовательностей, которой в формализации этого раздела нет. Доводится
более слабое, но содержательное утверждение для лестничных реализаций: при $\alpha_n\beta_n=n$ хотя бы один из
весов неограничен, то есть хотя бы один из операторов $a$, $a^\dagger$ неограничен на базисных состояниях.
Проверено в `Check.v`, раздел 2 (Closed under the global context):

```coq
Theorem ladder_weights_unbounded : forall al be : nat -> Q,
  (forall n, al n * be n == inject_Z (Z.of_nat n)) ->
  forall K : Q, exists n, K < al n * al n \/ K < be n * be n.
```

(к нему же относится уже доказанная `energy_unbounded`).

**(б) Поправить слова.**

> У него есть чисто алгебраическое следствие, объясняющее, *почему* $\hat q,\hat p$ не могут быть конечными
> матрицами — обязаны быть бесконечномерными (а в бесконечной размерности — неограниченными; последнее здесь не
> доказывается).

Заголовок раздела — слово автора; при желании оставить его без изменения достаточно этой оговорки.
