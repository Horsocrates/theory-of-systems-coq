   Для сеточной функции, периодической в этом смысле, слова страницы верны. Настоящая глава теорему не называет
   и условий не формулирует — это делает Глава 9.2 («$E(u^{n+1}) \le E(u^n)$ …, периодическая сетка»); там
   вопрос и решается. Здесь записано `ok` с пометкой.

6. **Перенос: «без изменения формы», «профиль лишь сдвигается»** (стр. 170–173). В `src` точный сдвиг доказан
   только при `nu = 1` (`transport_shift`, `ProcessTransport.v:120`). При `0 < nu < 1` шаг смешивает узел с
   предшественником; на примере самого файла (`Check.v`, раздел 7): профиль $(5,3,0,0)$ при `nu = 1/2` переходит
   в $(5/2,\ 4,\ 3/2,\ 0)$ — масса 8 сохранена, форма изменилась. Сохранение массы (`transport_mass`) доказано
   для одного шага при любом `nu`; для любого числа шагов оно следует индукцией без условий на края
   (`transport_iter_mass`, `Check.v`, раздел 5). Слова страницы описывают тип уравнения и о доказанном не
   говорят; предмет ведомости Главы 9.4.

7. **Волна: «фронт продвигается не более чем на один узел за шаг»** (стр. 165–168). Соответствует
   `wave_step_interior_zero` (`ProcessWaveEnergy.v:73`) — утверждению об одном шаге; итерации волнового шага в
   файле нет. Слова страницы тоже говорят об одном шаге. Предмет ведомости Главы 9.3.

8. **«Чтение авторских E/R/R-шапок опорных файлов»** (стр. 193–195, сноска 5). Разметка Elements / Roles / Rules
   стоит в четырёх файлах каталога `process/`; в двух файлах инфраструктуры (`GridFunction.v`,
   `FiniteDifference.v`), названных в сноске 1 опорными, её нет. Сноска 5 приводит одну шапку —
   `ProcessPDEGreen.v` — и приводит её верно.

9. **«Система сформирована корректно … нет самоотнесения (P1)»** (стр. 230–231). Формальной проверки за этими
   словами нет: записи `System` и применения P1 в шести файлах Части IX нет. Страница на стр. 190–195 сама
   называет разбор интерпретацией, а не утверждением о коде.
