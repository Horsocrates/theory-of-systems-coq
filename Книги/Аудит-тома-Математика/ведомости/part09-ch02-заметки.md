
```coq
(** Профиль периодичен с периодом N: u_{j+N} = u_j при всех j. *)
Definition gperiodic (N : nat) (u : grid_fn) : Prop :=
  forall j, u (j + N)%nat == u j.

Lemma gperiodic_N0 : forall N u, gperiodic N u -> u N == u 0%nat.
Proof. intros N u H. exact (H 0%nat). Qed.

(** Шаг сохраняет периодичность. *)
Lemma heat_step_gperiodic : forall r N u,
  (0 < N)%nat -> gperiodic N u -> gperiodic N (heat_step r N u).
Proof.
  intros r N u HN H j. unfold heat_step.
  assert (Hp : u (ppred N (j + N)) == u (ppred N j)).
  { destruct j as [|k].
    - destruct N as [|m]; [ lia | ]. cbn [Nat.add ppred Nat.pred]. reflexivity.
    - cbn [Nat.add ppred]. apply H. }
  assert (Hs : u (S (j + N)) == u (S j)) by exact (H (S j)).
  rewrite Hp, Hs, (H j). reflexivity.
Qed.

Lemma heat_iter_gperiodic : forall r N u n,
  (0 < N)%nat -> gperiodic N u -> gperiodic N (heat_iter r N u n).
Proof.
  intros r N u n HN H. induction n as [|m IH].
  - exact H.
  - cbn [heat_iter]. apply heat_step_gperiodic; assumption.
Qed.

(** Энергия не растёт от шага к шагу -- для всякого номера шага. *)
Theorem heat_iter_energy_step : forall r N u n,
  0 <= r -> 2*r <= 1 -> (0 < N)%nat -> gperiodic N u ->
  gf_norm_sq N (heat_iter r N u (S n)) <= gf_norm_sq N (heat_iter r N u n).
Proof.
  intros r N u n Hr Hr2 HN H. cbn [heat_iter].
  apply heat_step_energy; try assumption.
  apply gperiodic_N0. apply heat_iter_gperiodic; assumption.
Qed.

Theorem heat_iter_energy_mono : forall r N u n m,
  0 <= r -> 2*r <= 1 -> (0 < N)%nat -> gperiodic N u -> (n <= m)%nat ->
  gf_norm_sq N (heat_iter r N u m) <= gf_norm_sq N (heat_iter r N u n).
Proof.
  intros r N u n m Hr Hr2 HN H Hnm. induction Hnm as [|m Hle IH].
  - apply Qle_refl.
  - eapply Qle_trans; [ apply heat_iter_energy_step; assumption | exact IH ].
Qed.

Theorem heat_iter_energy : forall r N u n,
  0 <= r -> 2*r <= 1 -> (0 < N)%nat -> gperiodic N u ->
  gf_norm_sq N (heat_iter r N u n) <= gf_norm_sq N u.

(** Всякий набор значений в узлах 0..N-1 продолжается до периодического профиля. *)
Definition pext (N : nat) (u : grid_fn) : grid_fn := fun j => u (j mod N)%nat.

Lemma pext_gperiodic : forall N u, (0 < N)%nat -> gperiodic N (pext N u).
Proof.
  intros N u HN j. unfold pext.
  replace ((j + N) mod N)%nat with (j mod N)%nat; [ reflexivity | ].
  replace (j + N)%nat with (j + 1 * N)%nat by lia.
  symmetry. apply Nat.Div0.mod_add.
Qed.

Lemma pext_agrees : forall N u j, (j < N)%nat -> pext N u j = u j.
```

Посылка `gperiodic` выполнима: `pext_gperiodic` даёт периодический профиль по любым значениям в $N$ узлах;
пример главы — `pext 4 u_imp` (первый шаг даёт те же $1/2$ и $3/8$: `pext_imp_step1`). В том же пробном файле

   $r=\tfrac12$ её сохраняет и знакопеременный профиль (`heat_alt_energy_conserved_half`). Строгое убывание
   верно при $0<r<\tfrac12$ для профиля, у которого два соседних узла сетки различны (`heat_energy_strict`);
   пример главы под это условие подпадает (`imp_strict_instance`). В остальных местах страница говорит «не
   растёт».
4. **Стр. 149–150: «он сильнее (даёт количественную меру сглаживания)».** В формализации два утверждения
   независимы: ни одно не выведено из другого; `heat_step_energy` требует `0 < N` и периодичности, которых
   `heat_step_box` не требует, и говорит об одном шаге. Количественную меру (на сколько убывает энергия) даёт не
   неравенство, а баланс: `heat_energy_balance` (`Check.v`, раздел 5) — в файле главы его нет.
5. **Стр. 64, 200–203, сноска 9: «конечная сетка».** Профиль в `.v` — последовательность по всем натуральным
   номерам; `in_box` и принцип максимума говорят обо всех номерах, конечность входит через `N` в суммах и в
   `ppred`. Для принципа максимума это утверждение сильнее сказанного на странице. Значения в узлах с номерами
   от `N` и далее шаг пересчитывает как на полупрямой; с узлами сетки они согласованы только у периодического
   профиля (расхождение 1).
6. **Стр. 69–82: вывод формулы шага.** В файле шаг записан сразу в перегруппированном виде; запись
   $u_j + r(u_{j+1}-2u_j+u_{j-1})$ и её равенство определению отдельным утверждением не стоят (тождество:
   `heat_step_euler_form`). Величин $\Delta t$, $\Delta x$ в файле нет: `r` — произвольное рациональное число,
   равенство $r=\Delta t/\Delta x^2$ — чтение страницы.
7. **Сноска 2: «центрированный лапласиан (а не повторная прямая разность `dd`)».** Во внутренних узлах это одна и
   та же вторая разность со сдвигом номера: `heat_step r N u (S k) == u (S k) + r * dd u k` (`heat_step_dd`).
   Отличие — в узле 0, где левый сосед берётся циклически. Имя `dd` в `ProcessHeatEquation.v` не используется.
8. **Стр. 159–160: «значение 1 в одном узле, 0 в остальных».** Функция `u_imp` равна 1 в узлах 0 и 4 (узел 4 —
   копия узла 0, чтобы выполнялась посылка `u 4 == u 0`) и нулю в узле 8. Для одного шага на узлах 0..3 это тот
   же импульс; на многих шагах — см. расхождение 1.
9. **Стр. 61, 197: «равномерный предел — роль-предел».** В шапке файла роль-пределами названы $u(x,t)$ и
   непрерывный предел; равномерного профиля как предела по номеру шага в шапке и в файле нет. Сноска 9
   перечисляет ровно то, что стоит в шапке; утверждения о формализации здесь страница не делает.

## Вне главы (исходники)

- `ProcessHeatEquation.v`: шапка («finite periodic grid», стр. 4) и комментарий к разделу («centered in space,
  periodic», стр. 42) называют сетку периодической; в определении шага циклическим сделан только левый сосед, а
  условие на правый край стоит посылкой одной леммы и шагом не сохраняется (расхождение 1). Комментарий к
  `u_imp` (стр. 152: «Impulse profile on the 4-point periodic grid: u(0)=u(4)=1, else 0») — функция равна нулю
  в узле 8 и периодической не является. Счёт шапки («8 Qed») верен.
- `FiniteDifference.v:216`: `is_periodic N f := f N == f 0%nat` — периодичностью названо одно равенство; шаг
  `heat_step` его не сохраняет (`premise_not_preserved`). В `green_dirichlet_periodic` (`ProcessPDEGreen.v:87`)
  по той же причине стоят две посылки (`u N == u 0`, `u (S N) == u 1`).
- `ProcessPDEGreen.v`, шапка (стр. 10–12): «the discrete Green identity … and the Laplacian norm bound are
  exactly what the heat-equation energy estimate (Глава 9.2) needs» — доказательство `heat_step_energy` ни
  `green_dirichlet_periodic`, ни `lap_norm_bound` не использует; оно берёт из этого файла `ppred` и две леммы о
  сдвиге суммы. Глава 9.1 (сноска 4) это оговаривает.
- Шаги `transport_step` (`ProcessTransport.v:42`) и волновой шаг (`ProcessWaveEnergy.v:44`) используют тот же
  `ppred`, а волновой шаг — и правого соседа `S j`; сохраняется ли их посылка периодичности на многих шагах —
  предмет ведомостей Глав 9.3–9.4, здесь не проверялось.
- Имя `alt` занято (`src/nonstandard/StandardPart.v:83`); в пробном файле знакопеременный профиль назван
  `heat_alt`.
