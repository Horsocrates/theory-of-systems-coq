  set (c := Qabs (R n * R n - 2)) in *.
  set (d := Qabs (S n * S n - 2)) in *.

Qed.

Почему это верно. Для чисел $x, y \ge 1$ имеем $2|x - y| \le |x^2 - y^2| \le |x^2 - 2| + |y^2 - 2|$: отсюда и

$|x_n^2 - 2| = 1/q_n^2$, $q_n \ge n + 1$ (`Sqrt2Approx.v`).

Скорости сходимости в наброске явные: для ньютонова процесса $|x_n^2 - 2| \le 1/2^n$ (оценка грубая, действительная
скорость выше), для процесса цепной дроби — равенство $1/q_n^2$.

`ShrinkingIntervals_ERR.v` процесс деления отрезка пополам определён с произвольной функцией выбора половины —
`bisect_iter`, `bisect_process` (`:630`, `:841`), — и для него доказано `bisect_is_Cauchy` (`:845`). Выбора половины
по сравнению квадрата середины с двойкой в `src` нет; ни одна из двух теорем к процессу, связанному с условием

В `ContinuumLimitIsReal.v` доказано, что соседние подходящие дроби Пелля лежат по разные стороны от корня
(`brackets_root`), но свойство Коши там не выведено (шапка файла).

**В чём расхождение.** Доказана общая теорема о процессе сжимающихся интервалов; процесс сжимающихся
интервалов для $\sqrt{2}$ не построен, и о нём ничего не доказано. Слова «задающий $\sqrt{2}$» и «доказанно»
относятся к объекту, которого в формализации нет.

**(а) Довести формализацию.** Возможно, без аксиом, средствами того же файла. Набросок проверен (`Check.v`,
раздел 5; Closed under the global context):

```coq
(* левая половина, если квадрат середины не меньше двух; иначе правая *)
Definition sqrt2_choose (s : BisectionState) : bool :=
  Qle_bool 2 ((bis_left s + bis_right s) / 2 * ((bis_left s + bis_right s) / 2)).

Definition sqrt2_start : BisectionState := mkBisection 1 2.

Definition sqrt2_bisect : nat -> Q := bisect_process sqrt2_choose sqrt2_start.

Theorem sqrt2_bisect_Cauchy : is_Cauchy sqrt2_bisect.
Proof. apply bisect_is_Cauchy. reflexivity. Qed.

(* инвариант: 1 <= l, l*l <= 2 <= r*r, r <= 2, l <= r на каждом шаге *)
Lemma sqrt2_bisect_inv : forall n : nat,
  1 <= bis_left (bisect_iter sqrt2_choose sqrt2_start n) /\
  bis_left (bisect_iter sqrt2_choose sqrt2_start n) *
    bis_left (bisect_iter sqrt2_choose sqrt2_start n) <= 2 /\
  2 <= bis_right (bisect_iter sqrt2_choose sqrt2_start n) *
    bis_right (bisect_iter sqrt2_choose sqrt2_start n) /\
  bis_right (bisect_iter sqrt2_choose sqrt2_start n) <= 2 /\
  bis_left (bisect_iter sqrt2_choose sqrt2_start n) <=
    bis_right (bisect_iter sqrt2_choose sqrt2_start n).

(* явная оценка *)
Lemma sqrt2_bisect_quality : forall n : nat,
  Qabs (sqrt2_bisect n * sqrt2_bisect n - 2) <= 4 / Qpow2 n.

Theorem sqrt2_bisect_sq_to_2 : sq_to_2 sqrt2_bisect.
Proof.
  intros eps Heps.
  assert (H4 : 0 < 4) by reflexivity.
  destruct (Archimedean_width 4 eps H4 Heps) as [N HN].
  exists N. intros n Hn.
  apply Qle_lt_trans with (4 / Qpow2 n); [ apply sqrt2_bisect_quality | ].
  apply Qle_lt_trans with (4 / Qpow2 N); [ | exact HN ].
  apply width_shrinks; [ exact H4 | exact Hn ].
Qed.

Theorem bisect_gives_sqrt2 : gives_sqrt2 sqrt2_bisect.
Theorem newton_bisect_equiv : ProcessCore.process_equiv sqrt2_newton sqrt2_bisect.
```

Почему это верно: на каждом шаге $l^2 \le 2 \le r^2$ и $1 \le l \le r \le 2$; середина $m$ лежит между $l$ и
$r$, поэтому $|m^2 - 2| \le r^2 - l^2 = (r - l)(r + l) \le 4 (r - l) = 4/2^n$. Выбор половины идёт по сравнению
двух рациональных чисел и на цель не ссылается — в согласии со стр. 783–786. После добавления слова стр.
827–829, 844–845, 880–883 верны без правки; в сноске 17 тогда следует назвать `sqrt2_bisect_Cauchy`.

**(б) Поправить слова** (если формализацию не трогать):

> пополам, какая бы половина ни оставлялась на каждом шаге, — есть процесс Коши.[^17]

> (844–845) …и всякий процесс сжимающихся интервалов этим механизмом и есть процесс Коши; сам такой процесс для
