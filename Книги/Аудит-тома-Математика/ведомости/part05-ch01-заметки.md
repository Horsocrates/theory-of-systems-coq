5. **Полнота: частичный результат уже есть, а общий — доказуем** (стр. 856–859, 983, 1020–1021, 1071–1073).
   Статус «открыто» честен: общей теоремы в `src` нет. Но:
   - в репозитории есть `Completeness.v:464` `diagonal_converges` (`Closed under the global context`):
     последовательность Коши-процессов, у которой рубеж общий для всех членов и члены поточечно близки
     (`meta_cauchy`, :421), сходится к диагональному процессу `n ↦ s(n)(n)`. Глава его не упоминает; условие
     `meta_cauchy` сильнее, чем «Коши-последовательность классов», и зависит от выбора представителей;
   - пробный файл `_part05/ch01/Complete.v` (компилируется) формулирует полноту на классах через `rp_dist`:

     ```coq
     Definition class_cauchy (s : nat -> RealPoint) : Prop :=
       forall eps : Q, 0 < eps -> exists K : nat, forall k l : nat,
         (K <= k)%nat -> (K <= l)%nat ->
         cauchy_le (rp_dist (s k) (s l)) (cauchy_const eps).

     Definition class_limit (s : nat -> RealPoint) (L : RealPoint) : Prop :=
       forall eps : Q, 0 < eps -> exists K : nat, forall k : nat,
         (K <= k)%nat -> cauchy_le (rp_dist (s k) L) (cauchy_const eps).
     ```

     Оба понятия не зависят от выбора представителей (`class_cauchy_compat`, `class_limit_compat`). Доказаны:

     ```coq
     Theorem regular_class_complete : forall s : nat -> RealPoint,
       (forall k, ProcessCore.is_Regular_Cauchy (cs_seq (s k))) ->
       class_cauchy s -> exists L : RealPoint, class_limit s L.
     (* Print Assumptions: Closed under the global context *)

     Theorem class_complete_L4 : forall s : nat -> RealPoint,
       class_cauchy s -> exists L : RealPoint, class_limit s L.
     (* Print Assumptions: Axioms: ToS_Axioms.L4_witness *)
     ```

     Обе стоят на одной лемме-ядре (`diag_idx_is_cauchy`, `diag_idx_converges`): если у каждой точки `s k` указан
     номер `idx k`, после которого её представитель отходит от `s k (idx k)` не дальше `r k`, и `r k → 0`, то
     процесс `k ↦ s k (idx k)` есть Коши и служит пределом. У регулярного представителя номер известен заранее
     (`idx k = k + 1`, `r k = 2/(k+1)`) — допущения не нужны; у произвольного номер извлекается из доказательства
     Коши — это и есть `L4_witness`. Наивная диагональ `s(n)(n)` без номера не годится: при `s_k(n) = 1` для
     `n ≤ k` и `0` для `n > k` все точки равны нулю, а диагональ тождественно равна единице.

     Это точное формальное выражение тезиса § 1.6.4 («модуль как данные» против «доказательства в Prop»). Что
     остаётся за пробным файлом: предел в первой теореме не показан регулярным (для этого рубеж внешней
     последовательности тоже должен быть дан как данные). Если автор решит внести эти теоремы в формализацию,
     слова «открытым остаётся» на стр. 983, 1020–1021, 1071–1073 можно будет заменить на «доказана: для регулярных
     представителей без аксиом, для произвольных — на $L4$».
   - если теоремы не вносить, достаточно упомянуть имеющееся. Возможная вставка после стр. 1021: «Частично он
     уже пройден: в `Completeness.v` доказано (`diagonal_converges`), что последовательность Коши-процессов с
     общим рубежом сходится к своему диагональному процессу; для произвольной Коши-последовательности классов
