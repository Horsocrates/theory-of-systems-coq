## Расхождение 3. L¹: разность ступенчатых функций считается по месту в списке (стр. 11–12, 64–67; сноска 2)

**Было:**

> (11–12) $L^1$ — это пополнение ступенчатых функций по интегральной норме $\|f\|_1=\int|f|$; оно уже было
> построено в Главе 6.3 как процесс.

> (64–67) *интегрируемая функция есть предел ступенчатых функций по интегральной норме* $\|f\|_1=\int|f|$, то
> есть Коши-последовательность ступенчатых. Само пространство $L^1$ — это тип таких Коши-процессов, с точностью
> до отношения «совпадать в среднем» ($\|f-g\|_1\to0$, процессное чтение «почти всюду»).

**Проверка.** `src/analysis/L1Space.v`: `StepFun := list Step` (`:35`), где `Step` — значение и отрезок
`[step_left, step_right]`; требований к взаимному расположению отрезков нет.

```coq
Fixpoint step_fun_diff (f g : StepFun) : StepFun :=       (* :54 *)
  match f, g with
  | [], _ => []
  | _, [] => []
  | sf :: rf, sg :: rg =>
      mkStep (step_val sf - step_val sg) (step_left sf) (step_right sf) (step_valid sf)
      :: step_fun_diff rf rg

```

короткого. Интегральной нормой разности функций это является только тогда, когда оба списка заданы на одном
разбиении. Следствия (`Check.v`, раздел 7; все — Closed under the global context):

- `l1_equiv_nil_r`, `l1_equiv_nil_l`: всякий процесс `l1_equiv` пустому, и пустой — всякому;
- `c1_c0_not_equiv`: постоянные $1$ и $0$ на $[0,1]$ не `l1_equiv`;
- `l1_equiv_not_transitive`: отношение `l1_equiv` не транзитивно;
- `wideP`, `wideP_integral`: последовательность «ступень высоты $1$ на $[0,n]$» удовлетворяет условию
  `l1_cauchy` (норма позиционной разности равна нулю), а её интегралы `l1_integral_approx` равны
  $0,1,2,\dots$.

В файле об отношении `l1_equiv` доказана только рефлексивность (`l1_equiv_refl`, `:171`); теоремы «интегралы
стадий образуют последовательность Коши» нет (раздел с таким заголовком, `:99`, содержит три вспомогательные
леммы). То, что позиционная разность обрезает списки, в формализации уже отмечено в соседнем файле

удерживает интеграл, а `l1_equiv` не есть отношение эквивалентности, так что слова «с точностью до отношения»

   заданы на одном разбиении (`alignedL`). Тогда `l1_equiv` — отношение эквивалентности (проверено: раздел 7b),

   пространство с одним фиксированным разбиением конечномерно, и пополнением ступенчатых функций оно не

2. Полный: стадия $n$ — функция на двоичной сетке отрезка из $2^n$ равных ячеек; разность двух стадий
