### Разбор E/R/R

`ProcessExpLadder.v`.
- Elements: рациональные стадии `exp1_process N` = (1 + 1/(N+1))^(N+1) и `expt_process s N`; номера стадий.
- Roles: номер N — роль-разрешение; число 3 и число (1 − s/(k₀+1))^(−(k₀+1)) — роль-потолок, один для всех
  стадий; 3/(N₀+1) — роль-модуль (насколько близки любые две стадии за номером N₀); e и e^s — роль-пределы.
- Rules: неравенство Бернулли при x ≥ −1 и двойственное ему (1+x)^n(1 − nx) ≤ 1; касательная оценка
  x^m(x − (m+1)(x−y)) ≤ y^(m+1) при 0 ≤ y ≤ x.
- Диагностика P4: все утверждения — о конечных рациональных стадиях; свойство Коши есть свойство процесса
  (явный номер стадии для всякого ε); завершённый предел не строится.
- Не утверждается: рациональное число, являющееся пределом лестницы (число e как завершённый объект), и его
  иррациональность; лестница при s < 0; равенство e^(s+t) = e^s·e^t; что-либо о производной.

`EulerTrajectoryGeneral.v`.
- Elements: узлы `grid N k` = k/N; значения `euler_traj f y0 N k`; натуральные N и k.
- Roles: N — роль-разрешение; k — роль-стадия; h = 1/N — роль-приращение; t_k·h — роль-дефект метода для
  y′ = 2t; стадия траектории y′ = y при t = 1 — роль-приближение на лестнице к e.
- Rules: y_{k+1} = y_k + h·f(t_k, y_k), h = 1/N; при постоянной правой части шаг точен; при f = 2t траектория
  имеет замкнутый вид t_k² − t_k·h; при f = y шаг умножает на 1 + h.
- Диагностика P4: все утверждения — о конечных сетках и конечных стадиях; два индекса N и k остаются
  раздельными аргументами; измельчение сетки — направление процесса, предел N → ∞ не строится.
- Не утверждается: сходимость траектории Эйлера к решению для общей правой части; понятие решения как
  функции с производной; число e как завершённый объект; оценка ошибки для общей правой части.

### Разбор E/R/R

**ProcessODELinearLaws.v.** Elements: рациональные стадии Эйлера уравнений y′ = y, y′ = Ly, y′ = −αy при каждом
числе шагов; стадии лестницы (1 + s/n)^n при рациональном s любого знака; пары (y_n, v_n) осциллятора и сеточная
энергия E_n. Roles: 1 + Lh — множитель шага (роль-темп); (1 + Lt/n)^n — стадия, достигнутая к моменту t;
1 − αh — множитель затухания; 1 + h² — множитель энергии на шаге явного Эйлера; v — роль первой производной.
Rules: рекурсия Эйлера с правыми частями примеров даёт замкнутые формы; подстановка h = t/n превращает их в
стадии лестницы; лестница — процесс Коши; закон энергии и его следствие — исчезновение дрейфа к данному моменту
при измельчении сетки. Диагностика P4: все утверждения — о конечных рациональных стадиях; момент t и показатель
s — рациональные параметры; место завершённых e^t, e^{−αt} занимают лестницы стадий и свойство Коши.

**PriceDynamicsStability.v.** Elements: цены p_n, цель, темп α, отклонения — рациональные числа на каждом
конечном шаге; списки воздействий. Roles: 1 − α — множитель отклонения на шаге; |1 − α| — коэффициент Липшица
шага (роль-темп сближения с целью); цель — роль-неподвижная точка; `lipschitz_check`, `stability_signal` —
роль-признак (пороговая проверка числа). Rules: аддитивная динамика сохраняет расстояние между траекториями;
возврат к среднему умножает отклонение на 1 − α, и коэффициент решает: ≤ 1 — не растёт, < 1 — исчезает, > 1 —
растёт. Диагностика P4: «сходится к цели» записано как «отклонение меньше любого ε, начиная с некоторого шага».
