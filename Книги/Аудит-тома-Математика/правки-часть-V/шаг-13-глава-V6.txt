`udiff_chain_affine` (`FTC.v`) — цепное правило для
внутренней функции $g = c\cdot x + d$ при $c>0$, и
`udiff_chain_affine_neg` при $c<0$; обе — для внешней функции,
уважающей равенство рациональных. На них построены леммы
`ftc_u_substitution_affine` ($c>0$) и
`ftc_u_substitution_affine_neg` ($c<0$): Риманова сумма функции
$f'(cx+d)\cdot c$ по отрезку $[a,b]$ приближает приращение
$f(cx+d)$ — сеточная основная теорема для сложной функции. Саму
замену на уровне сумм даёт лемма `riemann_sum_affine_subst`: сумма
функции $\varphi(cx+d)\cdot c$ по сетке с шагом $s$ равна сумме
функции $\varphi$ по сетке с шагом $c\cdot s$ от точки $ca+d$ —
точно, при любом знаке $c$.
То есть подстановка $u = g(x)$ доказана лишь для линейной $g$; общая
замена с произвольной гладкой $g$ не формализована. Граница очерчена
