## ОС-1. Перепись по общей форме · 2026-07-21

**Разбор наличного.** Источник 2026-07-02 — адъюдицированный костяк в форме заметок
(пометки [есть]/[синтез]/[РЕШЕНО], связи в скобках): этимология iacere с
переворотом; ось универсальное/конкретное + позиционное чтение вне/изнутри;
субъективное = позиционное, не недостоверное; дуга данные -> восприятие ->
определённое при ЗДО; две честности (присвоение/упразднение внешнего взгляда);
весь свидетель субъективен, объективность = занятая позиция (ориентация двоякая);
критерий = универсальность, не согласие. Помечен открытым: грань «частный
объективный факт (данные) / универсальное».

**Сделано.** Источник переписан по общей форме: §0 этимология (чистовик, пометки
сняты) · §1 определение (+статусы Гл. 1) · §2 E/R/R · §3 механика-дуга ·
§4 свидетель/позиция · §5 две честности · §6 кейсы · §7 итог · переход ·

**Расширения (приложения канона 2026-07, БЕЗ новых тезисов; на вето автора):**

1. **Два лица объективного** (двуликость поля, ПИ-В2/В9): универсальная структура
   (рассуждение) / частные данные (встреча) — закрывает помеченную открытой грань
   «данные/универсальное»: это раздел ВНУТРИ объективного, не шов
   объективное/субъективное.
2. **Две ошибки = пара подмен статуса** (статусы Гл. 1, фигура РИ): объективизм

### ОС-2. Правило стиля + ответы В1–В3: лестница вместо дуги · 2026-07-21

**Правило автора (СТОЯЧЕЕ, для всего письма):** «мы больше не пишем в стиле глав —
у нас сайт-библиотека и страницы; отсылаться можно на другие темы, но не главы».

**ОС-В1 — ответ:** **уверенность = оценка вероятности** (формула автора; разбор —
тема веры и проверки; в списке субъективного — одной строкой).

**ОС-В2 — Давай:** переворот поднят до кейса «Переворот» (смена ролей слов = смена
онтологии эпохи; наша разводка — роль свидетеля вместо владельца слова — закрывает
тяжбу).

**ОС-В3 — поправка автора:** «Дуга неправильно берёт классы понятий, оставляй
только лестницу». Дуга (данные -> восприятие -> определённое) смешивала носитель,
акт и статус; механика перевёрстана на **лестницу знания** (данные -> считывание ->
информация -> запись) с чтением статусов по ступеням: данные объективны; считывание
и информация субъективны; запись субъективна по носителю и способна нести
объективное содержанием — при ЗДО. «Дуга» осталась только в стене честности как
запись о снятии.

**Исполнение по правилу стиля:**

  знания»;

Проверено: обе страницы перегенерированы, «Глава N» на страницах отсутствует, новые
