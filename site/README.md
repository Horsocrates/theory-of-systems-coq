# Сайт «Путь Мудрости» — скелет

Статический сайт: чистый HTML + один CSS, без сборки и зависимостей.
Локальный просмотр: `powershell -File site\serve.ps1` → http://localhost:8321/
(или двойной клик по `index.html`).

## Структура

```
site/
  index.html            Главная: девиз, лид, блок «Устав», 5 направлений
  ustav.html            Устав: кто мы · что утверждаем · принципы · метод · к читателю
  napravleniya.html     Обзор пяти направлений (вход в раздел)
  logika.html             └ Логика (основание, законы, Архитектура Размышления)
  metafizika.html         └ Метафизика (онтологические принципы, проявления Логики)
  teoriya-sistem.html     └ Теория Систем (Э/Р/П, уровни, процессы, результаты)
  etika.html              └ Этика (одна ось, добро/зло, свод, формализация)
  matematika.html         └ Математика (процессы, граница финитизации, том, результаты)
  kniga-matematika.html       └ Оглавление тома «Математика»: 20 частей, 120 глав, описания
  biblioteka.html       Корпус шести книг + статьи (само здание; направления — входы)
  formalizatsiya.html   Машинная проверка: числа, аксиомы, честные границы, репозиторий
  kontakty.html         Контакты (все данные — заглушки до решения автора)
  assets/style.css      Единственный файл стилей (светлая/тёмная тема автоматически)
  serve.ps1             Мини-сервер статики для локального просмотра (порт 8321)
```

## Принятые решения

- Название сайта: **«Путь Мудрости»** (2026-07-13).
- Девиз: **«Истина превыше всего»** — в эпиграфе главной и в подвале всех страниц.
- Машинная проверка — фишка, но не для главной: числа и разбор живут на странице
  «Формализация»; главная говорит с читателем на его языке.
- Порядок направлений: Логика (корень) · Метафизика · Теория Систем · Этика · Математика —
  повторяет лид главной.
- Репозиторий публикуем: ссылки на GitHub (ветка main) — на «Формализации» (репозиторий +
  файлы аксиом) и в «Контактах» (2026-07-13).

## Соглашения

- Навигация одинаковая на всех страницах; активный пункт помечен `class="active"`.
  Шапка/подвал продублированы в каждом файле — при изменении менять во всех
  (при росте сайта перейдём на генератор).
- Блоки `class="placeholder"` («Наполнение — следующий шаг») помечают каркас:
  что здесь будет, но текста ещё нет. Наполнение — отдельный этап.
- Квадратные скобки `[...]` — решения, которые принимает автор
  (подпись автора, почта, публикация репозитория, статусы книг).
- Числа на «Формализации» — из CLAUDE.md на 2026-06-04; при публикации пересчитать.
