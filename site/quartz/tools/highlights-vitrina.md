# HIGHLIGHTS · витрины (источник для генератора «Избранных результатов»)

Источник строк-витрин для `highlights2md.ps1`. В продакшене эти две строки —
комментарий-атрибут + фраза-витрина — могут встать прямо под заголовком записи
в `Книги/HIGHLIGHTS.md` (единый источник) либо оставаться здесь сайдкаром.
Пока сайдкар: большой HIGHLIGHTS правится в параллели.

Формат: `## H{N}` → `<!-- ВИТРИНА theme="…" level="…" part="…" cost="…" show="…" support="…" -->` → одна фраза-витрина.
level — самооценка новизны по шкале HIGHLIGHTS (новая теорема · синтез и наблюдение · новое обрамление известного · методы и изложение);
cost — допущения по `Print Assumptions`; support — опора в коде. На «Математике» печатается только часть тома (`-NoMeta`);
уровень, цена и опора — таблицей на «Формализации» (`-Formal`, маркеры `HLF:`).

## H68 — P4 + L5 = математика без ZFC

**Конечная актуальность и Порядок — математика без аксиом ZFC.** Наименьший выбор по Порядку в модели задан как μ-оператор теории вычислимости; над разрешимыми структурами он, по тезису тома, вместе с Конечной актуальностью несёт классический корпус этих структур — без аксиомы выбора и без завершённой бесконечности.

## H49 — выбор без AC (лестница)

**Выбор по Порядку без аксиомы выбора.** Роли «первый», «наименьший», «точка максимума» даёт Порядок; для разрешимых семейств над ℕ без аксиомы выбора проходит вся лестница — конечный выбор, счётный, зависимый и путь по лемме Кёнига, когда признак бесконечной ветви разрешим.

**Для квадратного корня из рационального числа граница вычислима над ℚ.** Полная процедура (корректность и полнота) решает, точный ли это квадрат; иррациональность *выводится* из её ответа (например, √(1/2) ∉ ℚ).

**Дзета-функция — процесс.** Частичные суммы — процесс Коши, аналитическое продолжение — новый процесс; эйлерово произведение — аналитическая запись однозначности разложения на простые множители; гипотеза Римана — утверждение, что каждый нетривиальный нуль есть неподвижная точка отражения s ↦ 1 − s̄: исследовательская линия тома, не решение.

**Числа Каталана — три независимых вывода.** Формула и рекуррентность получены конструктивно тремя путями — лемма о циклах (Дворецкий и Моцкин, 1947), принцип отражения (Эбли и Мириманов, 1923; по традиции его приписывают Андре) и разложение по первому возвращению, — и сверены друг с другом машинно.
