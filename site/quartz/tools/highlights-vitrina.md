## H68 — P4 + L5 = математика без ZFC
<!-- ВИТРИНА theme="Основания без ZFC" level="синтез + обрамление" part="[[10 Теория множеств без аксиомы выбора|Часть X]]" cost="13 Qed, 0 акс" show="index+registry" -->
**P4 + L5 = математика без аксиом ZFC.** Наименьший детерминированный выбор L5 формально совпадает с μ-оператором теории вычислимости; над разрешимыми структурами он вместе с P4 несёт весь классический корпус — без выбора и без завершённой бесконечности.
