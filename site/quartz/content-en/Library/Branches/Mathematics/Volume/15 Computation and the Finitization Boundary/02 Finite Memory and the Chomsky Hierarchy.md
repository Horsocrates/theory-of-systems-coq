## Memory as a Measure of the Distance to the Floor

Chapter 15.1 drew the *central cut* of computation: bounded halting is *decidable* (the Element side), unbounded halting is a role-limit. But between the decidable floor and the undecidable top there is no bare wall: the space between them is *graded*, and the parameter of the grading is **memory**.

Our system reads this as follows:

> *how much memory a computation is entitled to occupy is exactly the measure of how far it stands from
> the Element floor.*

Fixed finite memory is the floor itself: everything it recognizes is decidable. Each added memory resource—a stack, a bounded tape, an unbounded tape—is a rung up, toward the role-limit top (halting, 15.3). This chapter lays the floor (the finite automaton), finds its *ceiling* (the pigeonhole wall), takes one step up *concretely* (the language $a^nb^n$ and the grammar that generates it), and then reads the whole Chomsky hierarchy as *one Element / role-limit gradient*, marked out by memory—formalizing the *lowest* rung and reading the whole ladder as a gradient.

## The Finite Automaton: The Element Floor

A finite automaton is a *finite* set of states $Q$, a transition $\delta\colon Q\times\Sigma\to Q$, an acceptance predicate, and a start state. To recognize a word $w$ is to read its symbols one by one, driving the state by $\delta$. What is decisive here is the word *finite*: there are *finitely* many states, and this is a *fixed finite memory*; the run ends in $|w|$ steps; the question “*does the automaton accept $w$?*” is **decidable**—run it and read the acceptance bit.[^1]

This is the *Element* floor of computation: finitely actual, terminating, decidable, 0-axiom. A language is *regular* when some finite automaton recognizes it—that is, when *finite memory suffices*. The floor behaves as a well-behaved Element class: the regular languages are closed under complement, intersection, and union (the last two by the direct product of automata, where the memory is a pair of states). Not a shadow of undecidability: all the difficulty will come exactly when finite memory *ceases* to suffice.

## The Pumping Lemma: The Wall of Finite Memory

The floor has a ceiling, and its cause is the pure *pigeonhole principle*. Let the automaton have exactly $k$ states. Run a sufficiently long word: among at least $k{+}1$ visited states two must coincide—some state is *visited twice*. Between the two visits the automaton has gone through a *loop* that returned it to the same state; and the loop can be repeated (“pumped”) any number of times, and each time the automaton will end up in *the same* final state—hence the pumped words are either all accepted or all rejected.[^2]

This reads directly: *finite memory cannot count without bound*—it is forced to loop. The pumping property is the *signature* of bounded memory (the pigeonhole over states), not a trick. And it *marks out the edge of the floor*: every language that requires distinguishing unboundedly many “counts” lies beyond this edge.

## The Language $a^nb^n$ beyond the Wall; the First Step Up: The Stack

The witness beyond the wall is the language $\{a^nb^n\}$: $n$ letters $a$, then $n$ letters $b$. To accept it, the machine must check that the number of $b$’s equals the number of $a$’s, that is, *count* $n$—and $n$ is unbounded. Finite memory will not suffice. This is proved *unconditionally*, without any “pumping length”: for *any* automaton with *any* finite $Q$, run the prefixes $a^0,a^1,a^2,…$; by the pigeonhole principle two different prefixes $a^i,a^j$ ($i\neq j$) lead to *one and the same* state—and then the automaton *does not distinguish* $a^ib^i\in L$ and $a^jb^i\notin L$:

$$
\begin{gathered}
\exists  i\neq j:\quad \delta^{*}(q_0, a^i)=\delta^{*}(q_0, a^j) \\
  \Longrightarrow\quad
  \text{after appending } b^i \text{ the verdict is the same} — \text{the wrong language is accepted.}
\end{gathered}
$$

Therefore **no** finite automaton recognizes $\{a^nb^n\}$.[^3] Here $\delta^{*}$ is the extended transition (the run over a word).

*Relativity* matters: $\{a^nb^n\}$ is a role-limit *relative to finite memory*, not absolutely. Add *one* resource—a *stack* (last-in, first-out memory)—and counting becomes possible: push a mark on each $a$, pop one on each $b$, accept if the stack has emptied exactly. And indeed, $\{a^nb^n\}$ is *context-free*—it is generated by the grammar

$$
S \;\to\; \varepsilon \;\bigm|\; a S b .
$$

In our system this grammar is written as an inductive predicate and checked in both directions: it generates *exactly* $\{a^nb^n\}$.[^4]

This is how a **proved rung** is made: $\text{regular}\subsetneq\text{context-free}$. The language $\{a^nb^n\}$ lies in the upper class (a context-free grammar generates it) but provably not in the lower one (there is no DFA)—a genuine *strict* inclusion, machine-checked (0 axioms). The characterization of context-free languages by pushdown automata is a standard reading, not formalized separately.

## The Chomsky Ladder as an Element / Role-Limit Gradient

Putting the rungs together, we obtain a ladder in which each rung *adds memory*:

| **Class** | **Memory** | **Place in the gradient** |
|---|---|---|
| regular | finite control | the Element floor: membership is decidable |
| $\subsetneq$ context-free | ${}+{}$ stack | a *proved* rung (via $a^nb^n$) |
| $\subsetneq$ context-sensitive | ${}+{}$ bounded tape | a tier higher (LBA; not formalized) |
| $\subsetneq$ recursively enumerable | full tape | the top: membership reduces to halting (semi-decidable; 15.3) |

In ordinary textbooks the Chomsky hierarchy is a *taxonomy of grammar formats*. In our system it is **one graded Element / role-limit gradient**, and the parameter of the grading is memory. The bottom is the decidable Element floor; the top is the halting role-limit; each rung adds a memory resource and climbs the gradient. “*How undecidable for a given class of memory*” $={}$“*how far above the floor*.” The hierarchy turns out to be the *fine structure* of the central cut of 15.1: between “boundedly decidable” and “unboundedly a role-limit” there lies a *graded ladder*, not a wall.

**An honest boundary of tier.**  The *lower* tier is machine-checked (0 axioms): the decidability of the floor (`membership_decidable`), its closure, the pigeonhole wall, the DFA nonregularity of $a^nb^n$, and the first strict rung $\text{regular}\subsetneq\text{context-free}$. The rest of the ladder (context-free ${}\subsetneq{}$ context-sensitive ${}\subsetneq{}$ recursively enumerable), the Kleene equivalence (regular expressions${}\leftrightarrow{}$DFA),
and the characterization of context-free languages by pushdown automata are a standard mathematical reading, *not* formalized separately; the undecidability of the top (RE${}={}$halting) is the diagonal of 15.3.

## E/R/R Analysis: The Ladder as a Gradient of Roles

**Rules (L5).**  The ordered transition $\delta$ (the step of the automaton) and the production rules of the grammar ($S\to\varepsilon\mid aSb$) constitute the language; the pigeonhole wall is a derived rule that marks out the edge of the floor.

**Roles (L4).**  *Memory* is a role: finite control, a stack, a bounded tape, a full tape are resource-roles that a computation is entitled to carry. And the *class of a language* (regular, context-free, …) is a role-tier of the hierarchy: the place the language occupies in the gradient.

{

**Elements (L1${}+{}$P4).**  Concrete words, the inductive grammar `CFG_anbn`, concrete automata, finite runs. *Not* an element: a finite automaton for $\{a^nb^n\}$—it would reify unbounded counting into fixed memory (the pigeonhole rules it out).}

| **Component** | **What it determines** | **E/R/R category** |
|---|---|---|
| transition $\delta$; grammar rules $S\to\varepsilon\mid aSb$; the pigeonhole wall | the constitution and the edge of the language | Rule (L5) |
| memory (control / stack / tape); the class of a language as a tier | the resource and the place in the gradient | Role (L4) |
| words; the grammar `CFG_anbn`; automata; runs | finitely actual bearers | Element (L1${}+{}$P4) |

**P4 diagnostics.**  The ladder is a *gradient of role-limits*: “what a rung cannot do” is a role-limit *relative to* its memory; the floor is an Element (decidable); the ascent—the addition of memory—is an approach to the *absolute* role-limit (halting). In particular, $a^nb^n$ is *not* an absolute role-limit but a role-limit *relative to* finite memory: add a stack, and it becomes an Element of the next tier (hence the caution: nonregular $\neq$ uncomputable). To require finite memory to recognize $a^nb^n$ is to reify a role-limit into the Element floor: a level confusion, which the pigeonhole rules out.

## What the Chapter Has Prepared

The floor has been laid (finite memory: decidable membership), the ceiling found (pigeonhole / pumping), the first rung climbed *concretely* ($a^nb^n$ is generated by the grammar $S\to\varepsilon\mid aSb$ but recognized by no DFA—hence $\text{regular}\subsetneq\text{context-free}$), and the whole Chomsky hierarchy has been read as *one Element / role-limit gradient*, marked out by memory. The whole proved layer of the chapter is 0-axiom and machine-checked: DFA / NFA, the regular Element floor, pumping / pigeonhole, the nonregularity of $a^nb^n$, and the first strict rung. The upper tiers are honestly named as a standard reading, not passed off as checked.

The very top of the ladder—membership in a recursively enumerable language—is semi-decidable and reduces to halting ($\mathrm{halts}$): this is exactly the role-limit whose engine is the *fixed-point diagonal*. Chapter 15.3 opens this engine: one diagonal driving halting, Rice, Cantor, and Kolmogorov.
