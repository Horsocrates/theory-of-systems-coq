**2.6.4.9** · [[02 Domain Violations|Domain Violations (Type 2)]] → [[2.6 Domain 6 Reflection|2.6 Reflection]] · subtype: Immunization from Testing

**Formulation.** Attacking a true statement because it would “send the wrong message”

**Mechanism of the violation.** Reflection is blocked: the truth is rejected for the sake of preserving an illusion. An admission that absolute truth would destroy the lie.

**Example.** “We don’t know how to cope, but admitting it would send the wrong message”

**Diagnostic question.** Is “the wrong message” a reason to hide the truth?

**Psychological source.** Image management, fear of truth

**Related fallacies:** [[Mala Fides|Mala Fides / Arguing in Bad Faith]], 2.6.4
