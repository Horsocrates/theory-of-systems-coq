**2.3.5.7** · [[02 Domain Violations|Domain Violations (Type 2)]] → [[2.3 Domain 3 Framework Selection|2.3 Framework Selection]] · subtype: Irrelevant Criterion

**Formulation.** Something must be right/valuable only because much effort or sacrifice has been invested in it

**Mechanism of the violation.** The framework of evaluation: “much effort = valuable/true.” Effort determines neither the truth-value nor the value of a result. One can work hard on a mistaken project.

**Example.** “The blood of the martyrs”—one cannot question a cause for which people have died

**Diagnostic question.** Am I evaluating the result or the effort? Does sacrifice make a cause right?

**Psychological source.** Sunk cost, respect for sacrifice

**Related fallacies:** [[Cost Bias]], [[Argument from Inertia]], 1.B.2
