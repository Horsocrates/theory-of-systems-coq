**2.6.1.2** · [[02 Domain Violations|Domain Violations (Type 2)]] → [[2.6 Domain 6 Reflection|2.6 Reflection]] · subtype: Illusion of Completion

**Formulation.** Automatic acceptance of the existing state of affairs as right; any alternative is declared impossible

**Mechanism of the violation.** Reflection is closed: the current state is taken as final and the only one possible. “It is so = it ought to be so = it can only be so.”

**Example.** “It is what it is”; “Better the devil you know than the devil you don’t”; “If it ain’t broke, don’t fix it”

**Diagnostic question.** Do I accept this because it is the best option or because it is the current one?

**Psychological source.** Status quo bias, avoidance of effort

**Related fallacies:** [[Appeal to Tradition]], [[Argument from Inertia]]
