*Transfer / Name Dropping*

**Формулировка.** Ложная ассоциация известного лица или символа с несвязанным объектом

**Механизм нарушения.** Замена объекта: оценка переносится с авторитета на несвязанный объект. MLK на рекламе матрасов.

**Пример.** Фото MLK на рекламе матрасов; флаг Техаса для машин из Детройта; Чингисхан для китайского ресторана

**Диагностический вопрос.** Есть ли реальная связь между авторитетом и объектом?

**Психологический источник.** Halo effect, borrowed credibility

**Связанные ошибки:** [[Звёздная сила — Свидетельство знаменитости]], [[Вина по ассоциации]]
